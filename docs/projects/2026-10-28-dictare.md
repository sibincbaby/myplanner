## What it is

100% local, privacy-first voice layer for AI coding agents. You speak; dictare transcribes with a local STT model, routes the command to whichever coding agent is active (Claude Code by default, Codex, Gemini CLI), and reads back the response via local TTS. Switch agents by voice mid-session. Open protocol (OpenVIP): any tool can implement the SSE endpoint and become a voice-addressable agent. macOS install: `brew install dragfly/tap/dictare`. MIT license.

Key details:
- Both STT and TTS run locally (no cloud audio)
- Multi-agent switching by voice (say "switch to Codex")
- OpenVIP protocol: SSE endpoint spec any agent can implement
- Supports Claude Code (default), Codex, Gemini CLI
- v0.6.2 on PyPI — active development

## Why it scores

- **Weekend-buildable:** The core loop (local STT → command → agent stdin → local TTS) is a single Python script. An MVP taking inspiration from dictare can be built in a day.
- **Fills gap:** No other tool does multi-agent voice switching with a local STT/TTS stack. Claude Code has no voice input.
- **Novel:** The OpenVIP open protocol concept (any agent implements one SSE endpoint → voice-addressable) is a new interoperability primitive.
- **Daily utility:** Hands-free coding agent control is a genuine daily-use case for anyone who spends hours at a keyboard.

## Build angle

Extend or contribute to dictare, OR build a focused **Claude Code voice hook** that uses the OpenVIP protocol:

1. A Claude Code `UserPromptSubmit` hook that intercepts before each prompt to check for a voice-recorded file.
2. Local Whisper STT (via `whisper.cpp` or `faster-whisper`) transcribes the audio.
3. A `PostToolUse` hook reads the assistant's last response aloud via `pyttsx3` or `say` (macOS).
4. Optional: extend to multi-agent switching by detecting "switch to [agent]" patterns.

## Phases

### Phase 1 — STT input (Day 1, ~3h)
- Python script: record mic while key held (using `sounddevice`), write to WAV
- Whisper.cpp transcription (subprocess call or Python bindings)
- Output transcript to stdout / temp file

### Phase 2 — Claude Code hook integration (Day 1, ~2h)
- `UserPromptSubmit` hook: if `VOICE_INPUT` env var set, read from temp file instead of stdin
- PTT wrapper: shell script that sets `VOICE_INPUT`, records, transcribes, then launches `claude`

### Phase 3 — TTS readback (Day 2, ~2h)
- `PostToolUse` hook: after each assistant turn, pipe response text to `say` (macOS) or `pyttsx3`
- Config flag: `DICTARE_TTS=1` to enable/disable

### Phase 4 — Multi-agent switching (Day 2, ~1h)
- Detect "switch to codex" / "switch to gemini" voice patterns in transcription
- Update active agent env var and confirm by voice

## Blockers / risks

- Whisper.cpp installation varies by platform — macOS is straightforward via Homebrew, Linux requires building from source.
- Claude Code's `UserPromptSubmit` hook receives the prompt text after typing, not before — PTT must be a wrapper around the full `claude` invocation rather than a mid-session hook.
- Background mic recording requires microphone permissions on macOS (TCC); first run may need a one-time permission grant.
- The OpenVIP SSE protocol spec is defined by dictare — worth reading before building to ensure compatibility.
