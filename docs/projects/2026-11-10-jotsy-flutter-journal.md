# Jotsy — Offline-First AI Flutter Journal

**Source:** [jotsy.app](https://jotsy.app) (discovered via GitHub topics, updated Nov 4 2026)
**Score:** 4/4 (WB 1 · FG 1 · N 1 · DU 1)
**Shape:** build-your-own. Jotsy is a minimal open-source Flutter journal. Its architecture (offline-first SQLite, mood tracking) is a proven scaffold. Build a personal version that adds Claude-powered mood analysis and voice entry.

## Why this one

There is no open-source Flutter journal that combines: offline-first storage, Claude-powered AI analysis, voice entry, and mobile-first design. moodiary (seen Nov 7) uses Flutter + Rust (too complex for a weekend). Jotsy's codebase shows that the Flutter+SQLite+mood-tracking combination is a clean 1-2 session build, and Claude integration is a natural extension.

**Why FG=1:** The user's interest profile lists "diary/logging tools" under dev productivity. A private, offline-first journal with AI analysis covers that gap. Existing apps (Day One, Notion) are closed-source or cloud-first. The closest open-source match (moodiary) requires Rust.

**Why N=1:** No open-source Flutter journal combines offline-first storage + Claude mood analysis + voice entry. Jotsy is minimal (no AI). moodiary is complex (Rust). The gap is exactly this stack: Flutter + Drift + Claude.

**Why WB=1:** Flutter + Drift (type-safe SQLite) is well-documented. A basic CRUD journal with mood tracking and a Claude API call on save is a 1-session build. Voice entry via `speech_to_text` is another half-session.

**Why DU=1:** Daily journaling. The mood calendar view gives a week/month overview. Claude's reflection prompts make re-reading old entries more valuable.

## Stack recommendation

- **Flutter** — cross-platform (iOS, Android, macOS)
- **Drift** — type-safe SQLite ORM for Flutter; better than raw `sqflite` for schema migrations
- **Claude claude-haiku-5-5** — cheap per-entry mood analysis and reflection generation
- **`speech_to_text`** — Flutter plugin for on-device voice dictation
- **`flutter_secure_storage`** — store the Claude API key on-device, never in source
- **`fl_chart`** — mood trend chart for the calendar view

## MVP scope

A single-screen journal with AI mood tagging:

1. **Entry list + editor:** tap to create an entry, type or dictate text, save. Entries stored in Drift SQLite with `id`, `content`, `created_at`, `mood_score` (nullable), `mood_label` (nullable).

2. **On-save Claude call:** after saving, call Claude claude-haiku-5-5 with `"Analyze the mood of this journal entry in one word (e.g. Happy, Anxious, Reflective) and a score from 1-10."` Store the result.

3. **Mood calendar:** a 30-day grid where each day's cell is colored by mood score. Tap a cell to see that day's entries.

Out of scope (MVP): voice entry, cloud backup, search, reflection prompts.

## Phases

1. **Flutter scaffold + Drift (1 session).** Create a new Flutter project. Add Drift, generate the `entries` table schema. Build the entry list screen (ListView) and the editor screen (TextField + save button). Verify CRUD works offline on iOS Simulator and Android Emulator.

2. **Claude mood analysis (30 min).** Add `http` package. On entry save, POST to Claude claude-haiku-5-5 with a focused mood-extraction prompt. Parse the JSON response (mood_label + mood_score). Store in Drift. Display the mood label on the entry list tile.

3. **Mood calendar (1 session).** Build a CalendarWidget using `fl_chart` or a custom GridView. Each cell is colored on a green-yellow-red scale by mood score. Tap a cell to navigate to that day's entries. Add a weekly average mood sparkline at the top.

4. **Voice entry (1 session).** Add `speech_to_text`. Add a mic button in the editor toolbar. While recording, append recognized text to the editor in real time. Stop on button tap or silence timeout. This makes the journal accessible while walking or commuting.

5. **Reflection prompts (30 min, optional).** Add a "Reflect" button on each entry. Call Claude claude-sonnet-5-5 with the entry and the prompt "Ask me one thoughtful follow-up question about this journal entry." Display the question as a prompt for a follow-up entry.

## Effort

Phases 1–3: 1.5 sessions. Full implementation: 3 sessions.

## Blockers / risks

- **Claude API key on mobile:** `flutter_secure_storage` stores the key in the iOS Keychain and Android Keystore, not in app source. Never hardcode it. Add an onboarding screen that accepts and stores the key.
- **Claude API costs:** claude-haiku-5-5 at ~$0.0003 per 1K input tokens. A 500-word journal entry is ~375 tokens input + ~20 tokens output ≈ $0.00012 per entry. At one entry/day, this is about $0.04/month. Negligible.
- **App Store AI content policy:** Apple requires apps that generate text to disclose AI-generated content to users. Add a one-line disclosure in the app settings: "Mood analysis is generated by the Claude API (Anthropic)."
- **Offline-first vs. AI analysis:** when the device has no network, the Claude call will fail. Handle gracefully: skip mood analysis, store a `mood_pending: true` flag, and retry when connectivity is restored.
- **Privacy:** journal entries are personal. Never send them to any server except the Claude API. The Claude API does not train on API inputs by default, but add a privacy note in the app's settings screen.
