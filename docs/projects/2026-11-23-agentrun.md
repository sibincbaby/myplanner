# AgentRun — self-improving session wrapper for Claude Code

**Source:** [Parcha-ai/agentrun](https://github.com/Parcha-ai/agentrun) on GitHub — open-source agent management platform; Show HN Nov ~10 2026, 138 points; beta.53 as of discovery
**Discovered:** 2026-11-23
**Viability:** 4/4

> Parcha's AgentRun adds a self-improvement loop on top of any agent harness: after enough completed runs it compiles a workflow draft from learned patterns, keeps runs durable past 1 hour, and makes agents more fault-tolerant over time. The build here is a minimal local-first implementation of the same core idea — a Claude Code wrapper that accumulates a `skills.md` file from each session and automatically prepends that context into the next one. No server required; pure bash + Claude API.

- **weekend_buildable=1:** the core loop — wrap `claude`, after session ends ask Claude to summarize what was learned, append to `~/.agentrun/skills.md`, prepend on next launch — is under 150 lines of bash/TypeScript. Phase 1 is achievable in a single Claude session.
- **fills_gap=1:** Claude Code sessions today are stateless: nothing learned in Monday's session appears in Tuesday's. No existing open-source tool in this log automatically extracts and re-injects learnings across sessions without manual CLAUDE.md maintenance.
- **novel=1:** "agent improves itself across sessions" with no manual step is not found in prior-art searches within this log. Similar tools (agent-journal, agentlogs, claude-mem) capture transcripts but don't do the extract-and-reinject loop.
- **daily_utility=1:** fires automatically on every `agentrun start` session, so zero extra steps.

## Implementation Plan

### Overview

```
agentrun start          # launch Claude Code with accumulated skills prepended
agentrun review         # run the post-session extraction pass manually
agentrun skills         # print current skills.md
agentrun clear          # archive skills.md and start fresh
```

Each `agentrun start` does two things before handing off to `claude`:
1. If `~/.agentrun/skills.md` exists and is non-empty, writes a temporary system-prompt prepend with its contents.
2. After `claude` exits, invokes a brief extraction pass to identify any new learnings and append them to `skills.md`.

### Stack

| Layer | Choice |
|-------|--------|
| Runtime | Node.js 22 + TypeScript (or plain bash for Phase 1) |
| Agent harness | `claude` CLI (Claude Code) |
| LLM for extraction | Claude claude-haiku-5-5 via `@anthropic-ai/sdk` (cheap, fast) |
| Storage | `~/.agentrun/skills.md` (human-readable Markdown) |
| Session log | `~/.agentrun/sessions/YYYY-MM-DD-HHmm.txt` |

### MVP Scope (Phase 1–2, ~1 Claude session)

- `agentrun start`: reads `~/.agentrun/skills.md`, passes its contents as a `--prepend-system` flag (or writes a temporary CLAUDE.md prepend), launches `claude`, captures transcript to session log
- Post-session extraction: sends the last session log to Claude Haiku with a prompt like "Extract up to 5 bullet points of durable learnings from this session. Only include things the user would want to remember next time." Appends output to `skills.md`.
- `agentrun skills`: cat `~/.agentrun/skills.md`

**Done when:** running two sessions back-to-back, with something established in session 1 (e.g. "our test command is `pnpm test:unit`") appearing automatically in session 2 without manually editing CLAUDE.md.

### Phases

#### Phase 0: Setup (30 min)
1. `npm init` + TypeScript config + `@anthropic-ai/sdk`, `execa`
2. Confirm `claude --help` shows available flags; check if `--system` or `--prepend-system` exists; fall back to writing a `.claude/CLAUDE.md` prepend if not

#### Phase 1: Core loop (3h)
1. `src/start.ts`: read skills.md → spawn `claude` with prepend → pipe transcript to `~/.agentrun/sessions/` log
2. `src/extract.ts`: send last session log to Haiku → parse response → append deduped bullets to skills.md
3. `bin/agentrun`: thin bash shim that calls `npx ts-node src/start.ts "$@"`
4. Test: two back-to-back sessions confirm skill carry-over

#### Phase 2: Quality controls (2h)
1. Deduplication: before appending, ask Haiku "which of these new bullets are already covered by existing skills?" and drop duplicates
2. Staleness: each bullet tracked with `date_added`; `agentrun prune` removes bullets older than 90 days that haven't been referenced
3. `agentrun review` mode: shows proposed bullets and asks for y/n before appending (non-interactive default skips this)

#### Phase 3: Session indexing (2h)
1. `agentrun history`: lists past sessions with date, project (from `git remote`), and auto-generated one-line summary
2. `agentrun search <term>`: grep sessions + skills for a term
3. Per-project skills: if `~/.agentrun/projects/<remote-slug>/skills.md` exists, merge it with global skills.md on start

#### Phase 4: Self-compiling workflow draft (2h)
1. After N sessions on the same project, run a "workflow draft" pass: ask Claude to write a step-by-step checklist for the most common task pattern seen
2. Save to `~/.agentrun/projects/<slug>/workflow-draft.md`
3. Optionally export as a CLAUDE.md fragment

### Effort Estimate

~1.5 Claude sessions (6–8h): Phase 0+1 in one session, Phase 2+3 in the second, Phase 4 as a later optional add-on.

### Blockers / Risks

| Risk | Mitigation |
|------|-----------|
| `claude` CLI transcript capture | Use `script -q` or redirect stdout/stderr to tee; verify Claude Code doesn't suppress stdout in non-interactive mode |
| Skills file grows unbounded | Phase 2 deduplication + 90-day pruning; cap at 50 bullets hard limit |
| Haiku extraction quality | Prompt-engineer carefully; include "do not extract passwords, file paths, or repo-specific details that won't generalize" |
| `--prepend-system` flag availability | Check `claude --help`; if absent, write a CLAUDE.md fragment before launch and restore it after |
| Privacy: session transcripts | Store in `~/.agentrun/` (user home, not repo); document that sessions may contain code/secrets and should not be committed |
