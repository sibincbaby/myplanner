# AgentAFK — Walk-Away Coding Agent Harness with Editable Loop

## What it is

An open-source coding-agent harness that lets you start a long task, step away, and get notified (Telegram or desktop) when the agent needs input or completes. Unlike Claude Code's closed loop, every prompt, gate, and skill in agent-afk is editable. Full JSONL traces after every step.

Key features:
- Daemon mode — tasks outlive the terminal
- Telegram integration — reply from phone to unblock the agent
- Cross-session SQLite memory
- Built-in orchestrators: `/mint` (feature gen) and `/diagnose` (root-cause)
- Multi-model: Claude (all tiers), OpenAI, Ollama

## Why it fits

- Directly in the Claude/LLM tooling sweet spot
- Telegram notification pattern mirrors existing session management tools already in use
- Editable loop fills real gap vs. proprietary Claude Code — user controls the prompts
- Daily utility: every long coding session becomes walk-away capable

## MVP Scope (1-2 Claude sessions)

A lean "notify + audit" wrapper around Claude Code:
1. Spawn `claude` as a subprocess, capture stdout/stderr
2. Write every exchange to a JSONL trace file in `~/.agentafk/traces/`
3. On task complete or input-needed pattern → send Telegram message with context
4. Simple reply listener: incoming Telegram message → pipe into subprocess stdin
5. `agentafk start "fix the login bug"` CLI entry point

Skip for MVP: multi-model routing, /mint orchestrator, cross-session retrieval.

## Phases

### Phase 1: Core Runner (3-4h)
- CLI `agentafk start <task>` spawns Claude Code with stdio capture
- Detects "input needed" patterns (regex on ANSI output)
- Writes JSONL trace: `{ts, role, content}`

### Phase 2: Telegram Notify (2-3h)
- Bot setup: `/start`, `/status`, `/unblock <message>`
- Send "agent blocked" message with last 3 lines of context
- Pipe reply back into stdin

### Phase 3: SQLite Memory (2h)
- Store task summary + key decisions per session
- Surface last 3 relevant sessions via `deja-vu`-style search at session start

### Phase 4: Orchestrators (2-3h)
- `/mint <feature>` — structured plan → implement → test loop
- `/diagnose <error>` — read logs → hypothesize → patch → verify

### Phase 5: Multi-Model + Polish (2h)
- Swap in OpenAI/Ollama via one ENV var
- `agentafk history` TUI for browsing past traces

## Blockers / Risks

- Claude Code's stdout format changes with updates — regex patterns may need tuning
- Telegram Bot API needs a separate token and public webhook or polling
- Node ≥22 required (AsyncContext, native fetch)
- Walk-away safety: if agent requests filesystem ops, you're not there to approve — needs a safe-mode flag
