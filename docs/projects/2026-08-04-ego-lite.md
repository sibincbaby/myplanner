## What it is

A browser designed to be used by **you and your AI agent simultaneously**, without interfering with each other. The agent gets isolated "Spaces" — parallel browser workspaces within the same Chrome instance — with access to your existing logins, cookies, and stored credentials.

Unlike Playwright or Puppeteer (which spin up headless browsers with no session state), ego-lite gives the agent your real browser context. Claude Code can browse as you, fill forms you're already logged into, and run multi-tab research tasks while you work in other tabs.

The integration: an `ego-browser` agent skill that exposes browser functions as JavaScript tools. Claude Code calls `ego.open(url)`, `ego.click(selector)`, `ego.extract(query)` — the app routes these to the right Space.

## MVP Scope (1 Claude session)

Set up ego-lite and establish one end-to-end workflow:

1. Install ego-lite macOS app
2. Install `ego-browser` skill in Claude Code
3. Write a test workflow: "Open GitHub, find my open PRs, list their titles and CI status"
4. Have Claude Code execute it via ego-lite and return the result as a structured list
5. Verify the agent used your GitHub login without re-authenticating

That proves the core value in one session.

## Phases

### Phase 1: Install + Verify (1-2h)
- Download ego-lite from citrolabs.com, install macOS app
- Install `ego-browser` skill: `claude skills install ego-browser`
- Test basic navigation: `ego.open("https://github.com")` → get page title
- Test login detection: confirm ego-lite uses your existing GitHub session

### Phase 2: First Workflow — PR Monitor (2-3h)
- Write a Claude Code skill `/pr-status` that:
  - Opens GitHub PRs page for your repos in a Space
  - Extracts PR title, CI status (pass/fail/running), and last comment
  - Returns structured list to Claude Code session
- Test on 3-5 open PRs, verify accuracy

### Phase 3: Expense Form Automation (2-3h)
- Write a skill `/log-expense` that:
  - Takes `amount`, `category`, `merchant` as input
  - Opens your expense tool (Expensify, Notion, custom form)
  - Fills and submits the form using your existing login
  - Returns confirmation
- This replaces manual tab-switching for every expense

### Phase 4: Research Workflow (2h)
- Write `/research-topic` skill: opens 3-5 URLs in parallel Spaces, extracts key points from each, merges into a summary returned to Claude Code
- Useful for competitor monitoring, documentation lookups, news scanning

### Phase 5: Background Task Queue (3-4h)
- Write a scheduler that queues ego-lite tasks to run while you sleep
- Morning report: "While you slept, I checked your dashboards, logged yesterday's expenses, and summarised 12 new PRs"
- Store task queue in a local SQLite DB; ego-lite runs the queue on wake

## Blockers / Risks

- macOS only currently — Linux/Windows users blocked until citrolabs ships cross-platform support
- Session sharing is powerful but risky: if the agent misclicks a destructive action in your logged-in session, it's real — always test new workflows in a dedicated Space first
- ego-lite's `ego-browser` skill API may change between releases — pin to a specific version in your CLAUDE.md
- Automation of web UIs is inherently brittle — selectors break when websites update; test weekly and keep selectors commented with the UI element name
- Parallel Spaces consume significant RAM (each Space is essentially a Chrome profile) — limit to 3 concurrent Spaces on 16GB machines
