# herdr — Rust Terminal Multiplexer for the Agent Era

**Source:** [akapug/herdr](https://github.com/akapug/herdr) (AGPL-3.0, Rust, single binary)  
**Tagline:** "Run every coding agent side-by-side in one terminal, with real-time status per agent."  
**Discovered:** 2026-10-26 (cloud backup)

---

## Why it fits

Every AI coding agent — Claude Code, Codex CLI, Pi, OpenCode, Hermes — runs in its own terminal session. Context-switching between them is constant friction. herdr puts them all in one view: per-agent panes, a sidebar showing live agent activity (running / waiting / idle), and project workspace tabs.

The user profile calls out **Claude/LLM tooling**, **Agent UIs**, and **dev productivity**. herdr is the lowest-friction way to see and drive multiple agents at once without leaving the terminal. It is not a control plane or an orchestration framework — it is a display and interaction layer.

The differentiator vs. seen.json: hrdx (agent multiplexer seen previously) is Go and minimal. herdr is Rust, single binary, and adds per-agent status tracking + workspace tabs rather than just panes.

## Shape

**Adopt upstream** — install via Homebrew or the one-liner curl installer.

The custom-build angle: a lightweight **companion plugin** that exports herdr's per-agent activity data to a dashboard, Slack notification, or your diary/log tool (fits dev productivity + diary interest).

## Stack

- Rust (single binary, no runtime dependencies)
- Linux / macOS (README states these platforms)
- Integrates with: Claude Code, Codex CLI, Pi, OpenCode, Hermes, Grok, Gemini CLI
- AGPL-3.0

## MVP scope

1. `brew install herdr` (or curl one-liner).
2. Open a workspace with two panes: Claude Code on one project, Codex on another.
3. Verify the sidebar shows live agent status (running / waiting / idle).
4. Use the workspace tab system to separate two active projects.
5. Test that agent output in each pane is independently scrollable and selectable.

## Phases

1. **Install & first session (30 min).** Install, launch one Claude Code pane, confirm status sidebar.
2. **Multi-agent run (1 h).** Open Claude Code + Codex side-by-side on different branches of the same project. Drive a coding task from each.
3. **Workspace tabs (30 min).** Set up two named workspaces (e.g. work / personal project). Switch between them without losing pane state.
4. **(Later) Status export.** Write a small script that polls herdr's status output and logs it to your dev diary.
5. **(Later) Shell alias workflow.** Bind project-specific herdr layouts to short shell aliases.

## Effort

~1 h to install and have a real two-agent session running. ~30 min more to wire up workspaces.

## Blockers / risks

- **Linux/macOS only:** No Windows support per the README. Confirm before relying on this in a cross-platform workflow.
- **Star count variance:** Reports range from 15k to 31k depending on snapshot date — treat as roughly "large community" rather than a specific number.
- **AGPL license:** AGPL means any modified version distributed to users must ship source. Fine for personal use; check before integrating into a shipped product.
