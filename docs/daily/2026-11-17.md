## Scoring Notes

- **claude-code-dictation** (2/4): The trick is new: it runs the official `claude` client in a pty (vendored `pyte`), triggers `/voice`, scrapes the transcript and pastes it. Dictation runs on your Claude.ai plan, with no Gemini/Whisper key and no local model. This box is on X11, so it would run as-is. But `~/my-works/voice-coder` already does system-wide Linux dictation (Gemini, Malayalam→English, code-aware), so FG=0, and the repo exists, so N=0. It also depends on the `/voice` TUI layout (tested on 2.1.325), so any Claude Code update could break it.
- **spend-leash** (2/4): Hooks give per-task $ or %-of-5h-window caps, warn at 80%, and stop a call that repeats 5 times (editing a file resets the count). At 95% of the window it writes a handoff file instead of getting cut off mid-turn. Three repos in this lane in 48h (`spend-leash`, `Biint3/tokenjar`, `harkirat-data/LoopBudget`), plus the `aiusage-tracker` plan and `ccauto-resume`/`csuper` for the limit-reset side, so N=0. Its loop breaker is the one piece the nightly `claude -p` crons lack.
- **Focus** (2/4): Logged time next to what the machine saw, including Claude Code/Codex sessions by project. macOS-only (Apple Silicon build). On this Linux box, `lwr time` + `lwr log` (agent-driven daily work-log) and the `claw-diary` plan (2026-10-02) cover the Redmine side, so FG=0.
- **MoneyTracker** (2/4): Kotlin/Compose, no INTERNET permission, SQLCipher with a Keystore key, stores only paise/direction/party/last-4 plus a SHA-256 dedup hash. Its HDFC/SBI/ICICI/Axis/BoI regex set is worth borrowing. Same lane as `budget-widget` (11-11), the `flutter-sms-expense-ai` plan and PesaPilot, so FG=0 and N=0.
- **Muday** (2/4): Ethiopia-specific (AddisAI Amharic STT, Telebirr/CBE SMS), so N=1. NestJS + BullMQ + Redis + Postgres + React Mini App + Flutter is far past a weekend (WB=0). Its "ask a one-tap question when the amount is unclear" clarification step is the transferable idea for PesaPilot.
- **classify_poc** (2/4): The useful pattern: regex/layout rules fill strict fields first, the 0.6B model is asked only for the empty ones, and any value not present in the OCR text is dropped (anti-hallucination by construction). The device-cost screen (~586 MB model, load time, memory) is a good template for testing on-device models. It's a lab, not a daily tool, and PesaPilot uses Gemini, so DU=0 and FG=0.
- **claude-timeline** (2/4): A tidy mod (weighted task trees, "Request to continue", per-task Discuss thread). The superpowers task tools plus the existing trace-pane mods already cover progress tracking, so FG=0. Not daily.
- **pi-ui** (2/4): The fastest pi front end around (in-process SDK, 36 ms new session), with a full per-call inspector. You don't use pi, so FG=0 and DU=0.
- **agent-voice** (1/4): Speaches in Docker on a GPU, plus voxtype hold-to-talk and Hammerspoon over SSH. This is a personal dotfiles-style setup. `voice-coder` covers the input side, and `voice-reader` (seen 11-16) covers spoken replies.
- **agent-otel-kit** (1/4): Polished (Homebrew tap, `doctor`, Grafana + Perses). Claude Code OTel dashboards are an old lane, and `ccstat` plus the `aiusage-tracker` / `agentlens` plans cover local usage visibility.

## Worth Trying Instead of Building

- **spend-leash loop breaker for the crons**: the nightly `run-discovery.sh` / `run-idea-discovery.sh` jobs run unattended with `--dangerously-skip-permissions`. `npx spend-leash init` adds `PreToolUse`/`PostToolUse` hooks that stop a 5× repeated failing call, which is cheap insurance for those runs. Try it with a high $ cap so only the loop breaker fires.
- **claude-code-dictation as a fallback backend**: if the Gemini key or quota behind `voice-coder` ever fails, this keeps dictation working on the Claude plan. Read `vendor/` and the pty driver before running it.
- **classify_poc's "fill only the empty fields, drop anything not in the OCR text" rule**: apply it to PesaPilot's receipt/SMS capture prompt.
- **MoneyTracker's bank SMS regexes**: a ready-made Indian bank parser set for PesaPilot's SMS path.
