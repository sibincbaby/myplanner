**Top pick for this week:** **beacon.sh** (#1). Self-improving agent memory via Claude Code hooks hits every interest area. The beacon.sh concept maps directly onto the hooks system the user already uses (this discovery agent uses `Stop` hooks). Building the open-source version — a logger, a Claude-powered distiller, and a context injector — is 2 sessions. The gap is real and immediately useful. A related project (lorekit, 2026-11-09) proposed the storage format; beacon adds the automatic capture layer.

**Fastest win:** **Agent Inbox** (#2). Mailgun inbound routing + a FastAPI webhook + a Claude API call. The first version that replies to emails sent to the discovery agent can be built in a single afternoon. Unlocks async interaction with all existing agents.

**Best for evenings/mobile:** **Jotsy** (#3). Flutter on iOS Simulator is a smooth dev experience. Phases 1–2 (journal CRUD + mood analysis) are achievable in one session. Delivers a daily-use app that fills a gap no existing OSS tool covers.
