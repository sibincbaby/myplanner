## Scoring Notes

- **ag-ui** (1/4): Protocol infrastructure with 16k★, in Thoughtworks "Trial" since April 2026. WB=0 (a protocol spec, not a weekend build). N=0 (well-established, 16k★). Worth knowing about for wiring agent backends to frontends; no build plan warranted.
- **OpenChatCut** (2/4): Clean architecture (AGPL, MCP, Remotion rendering, 28 Skills), but video editing is non-trivial and DU=0 for most sessions. Lane is small (<100★). No adjacent project in seen.json, so no standing kill. FG=1 as AI-conversational local video editing with MCP is an underserved angle.
- **Zerg Client** (4/4): The concept that the agent itself opens and drives panes is new in open source. cmux, Shepherd Terminal, paneherd, and agent-terminal all require the user to wire panes; Zerg inverts this. Closed-source + Mac-only creates a clear open-source gap. Checked ADE Index `cap=parallel-agents`: 97 tools, none with agent-driven pane opening in OSS. tmux-based implementation is the plan.
- **Omnigraph** (2/4): A git-style typed graph DB with an MCP server is useful infrastructure, but WB=0 (database internals) and DU=0. Only 2.3k★ and April 2026 vintage; worth installing the MCP server to try it now. Build plan deferred.
- **Claude Personal Finance** (4/4): Anthropic launched read-only bank-connect on Nov 5 2026 via Plaid, US Pro/Max/Ultra only. This immediately creates a gap: non-US users, free-tier users, and anyone who wants local-only storage. `aurelio-finance` and `cc_expense_tracker` (already in seen.json) are both non-AI or narrow-country. FinScope fills the gap: CSV import (no Plaid needed for MVP), Claude for NL queries + categorization, SQLite local-only.
- **FlutterFlow AI builder** (0/4): A polished, funded app builder with existing users — not something to clone. Zero viable dimensions.
- **OpenOSINT** (1/4): Already at v2.29.0 with a PyPI release (`uvx openosint`) and cloud option. FG=0 — the tool already fills its own gap. Install and use it; don't build it.
- **agentsync** (1/4): 5+ competing tools in the same lane (agentsync, agentsync-cli, agent-config, brigade, agent_sync from yelmuratoff). Saturated lane; each tool is polished. DU=1 at setup time only.
