## Why Each One Stopped

- **Agent Autoloop:** the gap is real, because nothing here picks up work on its own beyond cron jobs, and Claude Duet is still a US waitlist. But it already exists as a polished MIT project, so there is nothing to build. It targets Node 24 on Mac or Linux and has Slack, Discord and desktop channels. Try it only if you have a steady queue of work for it. Same-shape prior art: `ableinc/coding-agent-loop` (08-21).
- **Agent Graph:** the only candidate with a new idea, a git graph as the main view, with no direct match in the `git graph agents` (287) or `worktree agents visual` (18) results. It still scores FG=0, because `claude agents` already shows which agents are waiting and the backlog holds workbench plans from 11-03 (`opcode`, `t3-code`, `worktrunk`). Its `PROMPT.md` is the cheap way to try the idea.
- **Small Print:** nothing here watches for changed tool descriptions, but the lane is already served: `mcp-surface-diff` 25★, `mcp-drift-detector` 15★, `Anchor` 11★, `mcpward` 8★. Install rather than build: `npx smallprint@1.6.0 check`. The CLI is MIT and the free plan keeps 25 pins and a daily email. Read what it uploads first, and don't paste in a config that contains tokens.
- **flutter-runner:** the official Dart MCP server registers launch, stop, logs and list-running-apps tools (`flutter_launcher.dart`), and `chukfinley/flutter-hot` (07-10) and `Baton` (08-31) have the same pitch. See the finding below.
- **flutter-dead-code-audit:** `ciach` 23★, `kareki` 16★, `flutter_prunekit` 12★ and `loam` 4★ already do this, and an agent can run them directly. It wouldn't be used daily either.
- **visual-plan:** `plannotator` has 9,848★, with `open-plan-annotator` 100★ and `canvas-flow` 21★ behind it. The `superpowers` brainstorming and plan-writing skills are already enabled here.
- **dx toolkit:** the journal half hits the backlog rule (12+ unbuilt journal plans). The dev-server half competes with `mcp-rewatch`, `devloop`, `devctl` and `Baton`, and background Bash and `/run` are built in.
- **readfirst:** `.claude/rules/` files with `paths:` frontmatter are the built-in way to scope notes to files, confirmed in the Claude Code memory docs. `repo map coding agent` also returns 165 repos.
- **CallMeClaude:** it needs a Mac and an iPhone, and this box is Linux. `radres/call-me` (32★, 07-10) has the same pitch and supports Android, and Remote Control already covers phone access. `saasagelabs/twring` is the same shape.
- **Portals:** first-party Remote Control covers phone access to local sessions, and the Mac and iOS apps are alpha.

## Worth Doing Instead

**The Flutter tooling here may already be installed but not reachable.** This session's start-up hook reported "Dart SDK not found in PATH", and the Dart MCP plugin did not connect. The SDK is at `~/flutter/flutter/bin` (Dart 3.12.1), but only `~/.zshrc` adds it to `PATH`, so non-interactive shells don't see it. Adding that line to `~/.zshenv` should expose the SDK to them. Whether that also fixes the MCP connection is untested. 26 `pubspec.lock` files sit under `~/my-works`.
