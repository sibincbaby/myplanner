## Why each died

- **cc-stretch**: the idea is new and well done (Ted Nelson's 1967 stretchtext, with Claude writing every level). The author measured that you see about 17% of the words before clicking. It is MIT and installs in one line (`/plugin install cc-stretch --marketplace pro-vi/cc-stretch`), so rebuilding it would just be a clone. Fills-gap is 0 because this setup already keeps replies short through the global CLAUDE.md conciseness rules and ponytail mode. Clicking also needs `/tui fullscreen`. **If you want to try it, install it. Don't rebuild it.**
- **reflex**: the "mine my session history for repeated workflows and propose skills" lane already had 4 entries before this one: `pi-skill-evolution`, `skill-finder`, `skill-workshop`, `vibe-spark`. You'd run it about once a month, not daily. The real gap is that `skill-creator` doesn't read your history, which reflex covers if you install it (`npm i -g reflex-skills`). Repo created 10-11, before the 48h window.
- **blink**: the attention-inbox lane is closed (`peon-ping` 5050★, `vibe-notch`, `code-notify`, `CCNotify`, `attnbox`; see the 09-24 note). Claude Code's own notification hooks plus the terminal bell cover it. Its pulse effect only works in Ghostty on macOS.
- **graphicle**: a 407-repo lane (`MegaMemory` 725★, `memtrace` 496★, `mnemon` 630★, `ai-maestro` 820★), and graphicle is itself a port of Graphify. A Rust code-graph indexer is not a weekend build.
- **simplefin-cli**: SimpleFIN Bridge connects US banks only. Prior art: `opencoffer` 19★ (SimpleFIN + BYO-LLM chat + MCP), `goetta-finance-mcp`, `ledgerglass-open`, `finance-reconcile-mcp`. Standing finance kill: `tomfunk/fungible` 108★.
- **Pulse Local**: closed-source Mac app with US-only bank sync (Plaid). The open part is the tuned model `PulseOS/pulse-local-qwen3-0.6b` on Hugging Face, which is useful as a reference if a finance plan from the backlog gets built. Standing finance kill applies.
- **finance-assistant**: same finance-lane kill. It's a ledger skill with Chinese-only prompts.
- **vscode-bridge**: the Claude Code VS Code extension already gives diagnostics and selection context through its IDE MCP. Prior art: `tjx666/vscode-mcp` 105★, `claude-ide-bridge` 38★. One part is a real fix: the plugin makes chat file links open in your chosen editor (anthropics/claude-code#81482).
- **agent-desk**: the agent-workbench GUI lane is the biggest cluster on record (`CodePilot` 6447★, `desktop-cc-gui` 4164★, …; see the 09-07 note), plus first-party `claude agents`. Too big for a weekend.
- **mahmut**: macOS-only (this machine runs Linux). The voice-for-Claude-Code lane is saturated (08-19, 08-30 and 09-03 notes).
