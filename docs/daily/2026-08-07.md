## Screening Notes

- **notebooklm-mcp-2026**: technically solid, weekend-buildable, and novel — but daily utility depends entirely on whether NotebookLM is in your workflow. Excluded on that ambiguity.
- **sub-agents-skills**: the install story (`/plugin install runner@sub-agents-skills`) means the full value is already one command away. Building your own cross-LLM router adds no unique angle when the upstream already works and is MIT-licensed.
- **parlor**: voice + vision on-device is compelling, but it's Python desktop (macOS/Linux, ~6 GB RAM), not Claude-backed, and not Flutter/mobile. Interest score 1 — below threshold. Two polished forks already exist (parlor-jarvis). Skip.
- **LangAlpha** fills a gap not yet in the backlog: the finance projects so far (financial-planning-agent, finance-assistant, copilot-money-mcp, finflutter) all target personal expense/budget tracking. LangAlpha's territory is *investment research* — DCF models, SEC filing analysis, options chains, earnings calendars — a different problem.
