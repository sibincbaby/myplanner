## Scoring Notes

- **Riji** (4/4): One sentence ("lunch 32, also fixed that Kafka bug") becomes three confirmed records in separate modules. The user's own PesaPilot already parses "dosa 20, tea 25" with Gemini, but its prompt ends with "if there is no expense, return an empty list", so anything that isn't an expense is dropped (`IngestNoExpense`). Ten prior-art queries found nothing that splits one input across money, work and diary. The nearest matches either keep expenses and a journal side by side with no AI (`cherriy`, `NotariFlow`, `PlanDo`) or send captures only to tasks and notes (`second-brain` 8★, `TaoSheng` 402★). The plan extends PesaPilot rather than starting another journal app. The repo already has about 10 unbuilt journal plans and 14+ finance plans, so building one more standalone app isn't the gap.
- **claude-gh-guard** (2/4): This is aimed squarely at the user's personal/work account rule. But git already solves it: `includeIf "hasconfig:remote.*.url:git@github-personal:**/**"` (git ≥ 2.36; this box has 2.43) can set `user.email`/`user.name` from the remote, and the `github-personal` SSH alias already picks the push key. The global `user.email` here is the work address, and personal repos rely on a manual repo-local override. Two lines of `~/.gitconfig` remove that step. Prior art: `github-identity-guard` and `gcamara/cc-hooks` (git identity + attribution guard), and `gitContext` (13★).
- **session-sentinel** (2/4): It fits this box (Linux, Python, GNOME Terminal tabs) and the 07-19 tabkeep plan was never built, so FG=1. But the crash-resume lane is six deep (`power_failure_resumer`, `reclaude`, `resume-claude-sessions`, `claude-resurrect`, `claude-recover`), and it's only useful after a crash. Worth installing as-is if reboots kill sessions often.
- **Fill Me In** (2/4): The eval is honest (62/72 vs 50/72 rated clear), but this is the "make Claude write for humans" lane (`nobuzz`, `claudish-to-english`). A custom output style does the same job with no plugin.
- **phasewise** (1/4): Phase-at-a-time plan running is already covered by the enabled `superpowers-extended-cc:executing-plans` / `subagent-driven-development` and the user's own `flutter-forge` / `rust-forge` phase-gated skills. Prior art: `sdd` (43★), `donnyclaude`, `astro-code`, `claude-task-flow`.
- **voice-reader** (1/4): The "voice for Claude Code" lane is saturated: `heard` (328★), `claude-read-aloud` (15★), `claude-code-speak`, and `read-aloud-mod` (11-02, the same offline Kokoro pitch).
- **rflutter** (1/4): No prior art found beyond a 2022 Node APK builder, but it's a Rust sync + tunnel + three-backend tool, not a weekend build, and local Flutter builds work fine on this machine.
- **Receiptdroid** (1/4): A careful offline OCR design, but it's built for hledger, which the user doesn't use, and PesaPilot already extracts expenses from bill photos.
- **csuper** (0/4): Only runs on macOS Apple Silicon. `ccauto-resume` already handles usage-limit resume here, and the forge skills cover phase cycles.
- **LedgerLite** (0/4): A polished React/Firebase PWA, but the user already has two Flutter expense apps (PesaPilot, CutMyCost), and the India finance lane is saturated.

## Worth Trying Instead of Building

- **git `includeIf` for the personal/work identity:** add `[includeIf "hasconfig:remote.*.url:git@github-personal:**/**"] path = ~/.gitconfig-personal` (with `user.email = sibincbaby219@gmail.com`, `user.name`) to `~/.gitconfig`. Personal repos then get the right identity automatically, with no per-repo `git config` step. Test it in one personal repo with `git config user.email` before relying on it.
- **session-sentinel:** `/plugin marketplace add cycanics/session-sentinel`, if a reboot or OOM has cost you sessions recently. Read its hooks first (Python, local only).
