## Screening Notes

- **Three unrelated things landed on the same day saying the same thing: nobody can tell whether the instructions they wrote for their agent do anything.** unchatty shipped an A/B harness — same repo, same questions, headless `claude -p`, rules on versus rules off, and a `score.py` that measures word count, average sentence length, em-dashes per 100 words, and header count. It reports one answer dropping from **393 words to 62**, and mid-sentence em-dashes going from 1.3 / 1.8 / 0.8 per 100 words to 0.0 / 0.0 / 0.0. Separately, atomic14 published *"The Output Style, It Does Nothing"*. Separately again, arXiv 2608.11095 asked *"Why Does Claude.md Keep Growing? Catastrophic Remembering in Agentic Coding."* A harness that proves a block works, a report that a feature does not, and a paper on why the file only ever grows. This machine's `~/.claude/CLAUDE.md` is **67 lines and 3,092 bytes**, every line of it a directive, none of it ever measured — and it is not even the largest instruction block in a session here, because the ponytail `SessionStart` hook injects roughly eighty more lines on top of it. See [ablate](../projects/2026-08-16-ablate.md).
- **The skill supply chain on this machine is 1,061 instruction files and 3,858 executable scripts, on auto-update, with nothing checking any of it.** Counted today: `find ~/.claude -name SKILL.md` returns **1,061**; `.sh`/`.py`/`.js` files under `~/.claude/plugins` number **3,858**; `settings.json` lists **eight** `extraKnownMarketplaces`, most of them individual accounts, with `autoUpdatesChannel: "stable"`. On the same day, arXiv 2608.05223 — *"Towards a Risk Assessment of Malicious Skill Files in Coding Agents"* — synthesized **2,826 malicious skill files** from 471 real shell commands and got **Gemini CLI to execute them in 95.5–96.1% of runs** and Qwen Code in 71.6–74.0%, with explicit safety recognition in **1.99%**. Judged by a three-model panel against a blind human gold standard, Cohen's κ = 0.85. And `run-discovery.sh`, the cron job that writes this digest, calls `claude --dangerously-skip-permissions` at 3am against every one of those files. See [seal](../projects/2026-08-16-seal.md).
- **claude-health-check is the tool this repo has been circling for a month, and the right verdict is to install it rather than rebuild it.** Cloned and read today: 3.3 MB, MIT, twenty-seven phases, its own eval suite and test harness. Phase 7 is *Skill Usage Metrics* — per-skill 30-day invocation, dormancy, misfiring and orphan detection read from `~/.claude/projects/**/*.jsonl` plus `~/.claude.json#skillUsage`. Phase 22 is agents-never-spawned. It also covers skill-listing-budget overflow, hook reliability, permission drift and dead memory links. That is precisely the "which of my 1,061 skills has ever actually fired" census that was the obvious second project today, already built, already tested, by someone else, yesterday. `novel = 0` is the honest score and the honest recommendation follows from it: run `make install` and point it at this box — the 382 session transcripts in `~/.claude/projects/` are the input it wants, and **eight of the twenty-four enabled plugins here** (rust-analyzer, dart-analyzer, kotlin-lsp, pyright, vtsls, intelephense, yaml-language-server, vgv-ai-flutter-plugin) did nothing at this session's startup except print an installation failure into context.
- **NexusMem has the best one-line problem statement of anything screened this week and is already MIT.** *"Your agent can read git log. It can't read the shell commands you tried that failed."* Exit codes, git commits and diffs, and project docs indexed into local SQLite. That is a real hole — the failures are where the information is, and they are the one thing that never reaches disk. It is also seven stars, MIT, and working, which makes `novel = 0` automatic; the honest move is `npm i`, not a weekend. `daily_utility = 0` is the one that keeps it off the list: on this box the agent already reads the repo and the git history directly, and the marginal content is a shell history that mostly belongs to the agent itself.
- **ThoughtDAG was the top Show HN of the day at 95 points and is not a weekend.** *"Chat history is long. Context is still invisible."* Nodes are messages, sources and clipped passages; edges are what actually enters the next request; you can delete an edge and regenerate. *"The graph is not a picture of context. The graph is the context."* MIT, local-first, desktop builds for all three platforms, Ollama and OpenAI-compatible. It is genuinely novel and genuinely good, and `weekend_buildable = 0` on a cross-platform graph editor is not a close call. `fills_gap = 0` too, for a specific reason: the context problem on this machine is not branching conversations, it is 1,061 skill descriptions and 67 lines of unmeasured directives arriving before anyone types anything — which is what both of today's picks attack.
- **longform-memory is a measured claim about a problem this machine does not have.** Constant token budget for long-form writing, 61,331 → 4,396 tokens, zero dependencies, runs on Cloudflare Workers. Publishing the before-and-after number instead of an adjective is the right instinct and rarer than it should be. `fills_gap = 0`: the longest thing generated here is this digest, and it is regenerated from scratch daily rather than continued.
- **Vesta is asking the question that matters and answering it with more machinery than a weekend holds.** An ontology over a resolved code graph where the vocabulary is learned from the repository itself and the rules come from users' corrections — ask what a change touches, ask where a kind of work gets done. That second question is the one that costs real time on an unfamiliar codebase. `weekend_buildable = 0`: a resolved code graph plus a correction-learning loop is a project, not a session.
- **Seven independent "tell me when the agent needs me" tools shipped in forty-eight hours, and this machine already has the feature.** herdr-agent-notify, Managerie, dsh-plugin-call-me, tockrock/agent-notification-adapter, benboerba/ai-agent-notify-skill, huguangyu666/dsh-plugin-notify, plus swairshah's menu-bar build. Yesterday it was permissions; today it is notifications. But `~/.claude/settings.json` here already carries `inputNeededNotifEnabled` and `agentPushNotifEnabled`, both on — the native feature covers it, so `fills_gap = 0` across the whole cluster. Managerie is the interesting one anyway (one menu bar, three harnesses, and you can *reply* from it) and it is Swift on macOS against a Linux box. dsh-plugin-call-me is the one with an idea worth stealing later: the agent rings your phone and *what you say steers the run*, which is a strictly larger channel than yesterday's approve/deny — but escalation was yesterday's project and this is a DeepSeek Harness plugin.
- **ai_guardrails is the only Dart entry worth reading and it is filed, not built.** On-device PII redaction, prompt-injection and secret detection, output validation, pure Dart with zero network calls, Apache-2.0, zero stars, one day old. `novel = 1` for keeping it entirely off the wire. `daily_utility = 0` for the plain reason that there is no Flutter AI app in production here to guard — this is the shape to reach for when there is.
- **copilot-hooks is yesterday's project ported to the wrong agent.** Tool-approver with auto allow/deny/ask, plus worktree-trust. Same structure as [airlock](../projects/2026-08-15-airlock.md), aimed at Copilot CLI, two stars, no license file. Worth noting only because it makes four harnesses in three days that have each grown the same permission-gating layer independently.
