## Screening Notes

- **llm-wiki-agent is the strongest find this cycle.** 3.5k stars with active maintenance, and it fills a real daily gap: knowledge accumulated in Claude Code sessions currently evaporates. The contradiction detection at ingest time (rather than at query time) is the architectural differentiator — it makes the wiki reliable rather than just large. The plan adds a CLI wrapper, daily digest, browser bookmarklet, and voice capture layer on top of the existing tool rather than reimplementing it.

- **qwen-voice fills the gap left by vclaude.** VoiceClaude (2026-08-26) is a one-turn voice interface to Claude API. qwen-audio-agent introduces full-duplex voice control of a long-running Claude Code agent process — you talk while it executes tasks, interrupt with barge-in, and hear status narration as tools fire. These are different enough to build in parallel. The personal build (`agentvoice`) uses local Whisper + Claude Code subprocess rather than DashScope to remove the cloud API dependency.

- **claude-video-vision is install-and-use, not build.** The Phase 1 plan is 1 hour of setup. The value is the batch playlist analyser (Phase 2) which feeds video summaries into the llm-wiki knowledge base — the two plans compose naturally. Install this the same session as llm-wiki.

- **flutter-ultra-mcp scored 3/4 but weekend_buildable = 0.** Installing 8 MCP servers with 295 tools is not a build; it's a configuration. And what you build with it (a Flutter app driven by Claude Code) is a multi-session project. Flagged as "adopt immediately" rather than "build this weekend."

- **langalpha scored 2/4.** The FastAPI + LangGraph + React + Postgres + Docker stack is too large for a weekend session. Also touches the finance lane. Skip.
