## Why each died

- **catnap**: An install row, not a build. The "hand off at a clean break instead of auto-compacting" mod lane already has `alexknowshtml/claude-auto-handoff` (97★, a mod, 10-03) and `REMvisual/claude-handoff` (65★, a mod), plus `handoff-skill`, `ccompactor` and `sctxx`. It also sits in the session-memory-across-compactions lane, which the 09-03 note marks as an automatic `novel=0`. If mid-task compaction bothers you: `claude plugin marketplace add LippInc/catnap && claude plugin install catnap@lippinc`.
- **ModVet**: Mods are a new surface, and a mod-specific pre-install vet has almost no prior art (3 hits, none mod-shaped), so N=1. But you don't install third-party mods often enough for a scanner to pay off, so FG=0 and DU=0. Those are usage judgments: the 2.1.304 changelog's mod scan only checks for secrets when you *share* a mod, so it is not a first-party kill. If you start installing others' mods, `pip install modvet` is zero-dependency.
- **Finance OS**: A real, polished PWA (budgets, net worth, offline queue), but it's iPhone-first and Google-Sheet-backed, with no AI past the AGENTS.md setup. Personal finance has 19 unbuilt plans in this repo, so FG=0 under the backlog rule. N=0: apps built on Google Sheets are a crowded genre.
- **earshot**: macOS-only (`say`, AirPods head gestures), and this box is Linux. The voice-for-Claude-Code lane is saturated (09-03 and 08-30 notes), so N=0.
- **personal-finance-visualizer**: A stdlib-only skill that turns normalized CSV into ring charts. Useful once a month, not daily. The `fungible` superset (08-30 note) and the finance backlog kill it.
- **Mnemoloci**: An ambitious engine (hashing, transactional vault writes, review queue, graph), so not a 1–2 session build. Session recall dies to `ctxrs/ctx` (1,121★), and the journal backlog already has 12+ unbuilt plans.
- **claudeweaver**: Agent kanban over Markdown tickets is already `jaira`, `agent-board`, `rakesh97/kanban`, `ticket-takeaway` and `kanban-tui`, so N=0. Its click-to-note overlay is the `stagewise` lane.
- **config2mcp**: `RonieNeubauer/cli2mcp` (12★) and `click-to-mcp` (8★) already wrap CLIs. In Claude Code the agent already has Bash, so FG=0.
- **Harp**: A macOS `.dmg` only (Warp fork, AGPL), so WB=0 and DU=0 on this Linux box. It's also killed by the first-party agents view (2.1.302: `claude agents`, peek panel, "agents waiting on you" count) and the 09-07 agent-workbench lane.
