## Screening Notes

- **LWC is the cleanest find this cycle.** Only 48 stars but the architecture is fundamentally different from both llm-wiki-agent (yesterday) and Memorix (Aug 26). Those are human-facing tools: you drop in documents or use MCP to read/write memories. LWC is a machine interface — the AI agent itself proactively writes, links, and recalls structured knowledge between sessions. The CodeGraph layer (30+ languages, cross-session symbol resolution) means a coding agent can recall what a function does across projects without re-reading source. Rust + SQLite is the right stack: deterministic full-text search, zero-latency local reads, no external service dependency.

- **OpenCockpit's Smart Bubbles are the differentiator.** The multi-engine IDE (Claude/Codex/Ollama in tabs) competes with several prior picks. But "Smart Bubbles" — agent-controllable Chrome, Postgres, MySQL, Redis interfaces — is architecture that has not appeared in any prior plan. The agent can query a live database, inspect a web page DOM, and check a Redis cache key, all without leaving the IDE. The LAN-shareable code review (no SaaS) is also immediately useful.

- **NextClaw's Panel Apps are unique.** Most agent workspaces discard intermediate artifacts. NextClaw's Panel Apps are mini-apps built during a task that persist in the sidebar — a SQL query form, a markdown previewer, a test runner button. Scheduled workflows (recurring daily briefs, automated checks) are the other gap-filler: no other pick in the past week has this as a first-class feature.

- **claude-voice scored 1/4 — third voice tool this week.** Kevthetech143/claude-voice (Aug 26) and qwen-audio-agent (Aug 27) already cover the voice lane. Skipping.

- **CLI-Anything scored 2/4.** 48k stars means it's well-established OSS, not a novel find. The automated 7-phase pipeline that generates CLI wrappers for desktop apps is powerful but this is a tool to adopt, not build — and it's already everywhere. If building agents that need to control GIMP or Blender, it's the install, not the discovery.

- **Gnosis (3D office) has gaps already filled.** The Obsidian integration is covered by claude-obsidian (Jul 30). The phone-based agent approval is covered by Pulse (Jul 15). The 3D office floor is novel as a visualization but not a daily utility. Score 2/4.
