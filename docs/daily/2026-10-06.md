## Viable Projects

- **[Impeccable: AI design language for better UI](../projects/2026-10-06-impeccable-ai-design-language.md)** — One install that gives Claude Code, Cursor, and Gemini CLI a shared design vocabulary: correct spacing tokens, typography rules, contrast requirements, and 23 anti-pattern guards. GitHub built it into Copilot Pro. The personal install is a 10-minute `npx skills add` + a local token-override file to use your project's actual colors. Immediate visible improvement in AI-generated UI quality — the "Inter font + purple gradient + nested cards" default is gone.

- **[ClaudeCodeExtension: Visual Studio .NET extension for Claude Code](../projects/2026-10-06-claude-code-extension-vs.md)** — The gap VS Code filled for JS/TS developers 18 months ago, filled for .NET/C#/MAUI developers now. Image paste (Ctrl+V screenshot into prompt), inline diff viewer, session history, usage tracking, and support for 8 agent backends in one VSIX. Zero build time — Marketplace install + 15-minute settings config. Daily improvement for every Visual Studio session.

- **[Echo: local-first AI journaling with voice + MCP](../projects/2026-10-06-echo-local-ai-journaling.md)** — Echo runs entirely on-device: Whisper transcribes voice memos, Claude Haiku (or Ollama) organizes entries into timeline cards. The weekend build adds an MCP server with `search_journal`, `recent_entries`, and `day_summary` tools, so Claude Code can answer "what was I working on Tuesday?" from your actual journal history. Stack: Node.js + Echo daemon + MCP SDK + SQLite FTS5. About 3 hours to a running journaling habit with AI search.

- **[Fin: MCP server for personal finance](../projects/2026-10-06-fin-mcp-personal-finance.md)** — Lighter than finlynq (Oct 5) and MyFinance MCP (Oct 4): a single stdio MCP server with a SQLite backend, no Docker. Handles multi-account balances, auto-categorized transactions, monthly budgets, recurring bills, loan amortization, and salary allocation. The workflow: log "spent €42 at Lidl" in Claude Desktop chat and ask "how's my grocery budget tracking?" — zero context switching. MVP is 2 hours of data entry to get 30 days of history in.

- **[Agent-Reach: zero-fee internet access for AI agents](../projects/2026-10-06-agent-reach-internet-cli.md)** — Adds Reddit, Twitter, YouTube, GitHub, Bilibili, and XiaoHongShu read+search to any MCP-compatible agent with a single install. The practical unlock: before picking a library, your Claude Code agent can search GitHub issues and Reddit threads for known pain points without you copy-pasting results. 77k stars, launched September 2026. 15-minute install + 30-minute verification.
