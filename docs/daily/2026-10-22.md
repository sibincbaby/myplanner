## Why each died

- **Wristle**: Nobody had made a watch-as-dictation-mic before, so N=1. But it needs a Wear OS watch plus Hex or Handy on the PC, and only Windows 11 + Pixel Watch 4 have been tested (Linux X11 is in the code but not tested). The dictation lane is saturated, so FG=0 and DU=0.
- **claude-log-skill**: Clean and confirm-before-send, but this repo already has 12+ unbuilt journal/task-log plans, so FG=0 under the backlog rule (10-15 note). The decision-log lane is crowded, so N=0.
- **Spark HUD**: Falls in the closed usage/cost lane (`TokenTracker` 1,723★, `agentacct`, 211 repos). First-party `/usage` now also turns its warnings into one-key fixes (2.1.305), so FG=0 and N=0.
- **AI Expense Tracker**: Hits three interest areas (finance, mobile-first, voice) and is well made: no backend, IndexedDB, BYO Anthropic key. But the finance backlog has 19+ unbuilt plans plus the 10-21 `mula` fork plan, so FG=0. Receipt-snap → Claude is a crowded genre, so N=0. It's also unlicensed, so it can't be forked.
- **agent-traffic**: A 6-deep lane: `gruzd1sok/buildq` (10-20, "one Xcode build at a time across every agent"), `BRANDAY/unreal-agent-hub` (10-16), `AyanBhardwaj1/Sentry` (08-01, pre-edit guard for parallel agents), `Kweiza/yoink`, `hiroyuki0504/agents-kit`, plus `porthaven` for port clashes. N=0. If parallel APK builds ever freeze the box: `/plugin marketplace add goldyndevs/agent-traffic`.
- **learn**: The ELI5/explain-my-session lane is closed (`attention-span` 1,150★, 10-01 note), and first-party `/recap` covers it. Zero-dependency HTML lessons are nice, but you'd use them once in a while, not daily.
- **claude-agent-tree**: Killed by the first-party agents view (2.1.302: `claude agents`, peek panel, "agents waiting on you").
- **agentty**: Killed by first-party Remote Control (spawn-mode messages improved again in 2.1.305), and terminal-in-browser for agents is a 10+ repo lane (09-26 note).
- **Geckobox**: A clean-room clone of Cua Spaces (says so in its README), so N=0. Its local sandboxes are macOS VMs, so WB=0 on Linux. This box only needs SSH + tmux for the same thing.
