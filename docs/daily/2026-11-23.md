## Scoring Notes

- **AgentRun (4/4):** Parcha-ai/agentrun wraps any agent harness (Claude Code, Codex, etc.) and adds a self-improvement loop: after 20 runs it auto-compiles a workflow draft from learned patterns, durable execution past 1 hour, fault-tolerant restarts. WB=1: a minimal version (session wrapper + skills.md accumulator) is one Claude session. FG=1: no existing tool in this log's scope persists learnings across Claude Code sessions automatically. N=1: the "agent improves itself" framing is not represented in prior-art searches. DU=1: fires on every dev session. ⚠ Note: `Parcha-ai/agentrun` is the most active fork; several forks exist on GitHub.
- **heard (4/4):** reads Claude Code and Codex session progress aloud on macOS using local Kokoro TTS (no account) or ElevenLabs/Speechify. Fires on finish / fail / needs-approval events via Claude Code stop hooks. WB=1: hooks + macOS `say` fallback is under 100 lines for a working MVP. FG=1: voice readback is the complement to voice input (duongntbk/voice-to-code, already seen) and nothing in the log fills that direction. N=1: "agent speaks to you" is distinct from every voice-input tool in seen.json. DU=1: fires on every Claude Code session automatically. License: Apache 2.0, engine open source; check whether the macOS app is separately closed-source before using releases directly.

WB=1: a Claude Code stop hook that dumps transcript + `git log --oneline -1` context to a local JSON store is under 50 lines. FG=1 [cloud, unverified]: no tool in seen.json links agent transcripts to commits; local backlog check not possible from cloud. N=1: the commit-linking angle is novel in the voice/diary/log lane.
