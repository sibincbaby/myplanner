## Why Each One Stopped

- **claude-code-recursive-delete-guard:** the gap is real here, because `run-discovery.sh`, `run-idea-discovery.sh` and `ccauto-resume` all run with `--dangerously-skip-permissions`. The new `permissions.blockWritesOutsideWorkingDirectories` setting only covers Write, Edit and NotebookEdit, not Bash. But this lane is already full (`claude code dangerous command hook` returns 46 repos, led by `nomos` 19★), and this repo is one standard-library Python file, so there's nothing to build. See below.
- **UsageResetter:** menu-bar and tray only, for macOS and Windows, so it doesn't run on this Linux box. `claude usage window schedule start` returns 15 repos (`claude-usage-stager` 6★, `warmup` 3★, `claude-min-max` 2★), and `fidpa/claude-window-scheduler` already supports Linux through systemd. A single crontab line does the same job. See below.
- **Footnote:** the closest thing to a new idea today. The nearest match in the broadened searches is `ehutt/arc` (5★). It still hits the backlog rule, because this planner already holds 12+ unbuilt journal and task-log plans. Writing to five different trackers is also more than a weekend, so an MVP would have to pick one.
- **OnlyRead:** the gap is real because Claude in Chrome acts inside signed-in accounts, but this is something to install rather than build. Telling reads from writes on every site is the hard part, and it's already done here. `opena2a-org/ai-browserguard` (6★) is an older take on the same idea. I haven't tested either.
- **ASR Recursive Improvement Loop:** the method is new to this log. An agent reads your dictation history, you confirm the mistakes, then you record and train on those words. `talax-dictation`, `offtype` and `idiolect` correct text or vocabulary, and their descriptions don't mention retraining a model. It doesn't fit this box, though: the CPU is an i5-1155G7 and `nvidia-smi` isn't installed, so fine-tuning needs a rented GPU. It also needs an all-day dictation habit first, and the only local voice tool, `voice-coder`, transcribes files.
- **agent-trace:** three mods already have this pitch (`claude-agent-trace` and two `claude-code-trace-waterfall` repos), and `delexw/claude-code-trace` (385★) views the same data from logs. Ctrl+O and the OTel events already cover the occasional need.
- **AIVault:** `agent skills lockfile` returns 64 repos, led by `Ski` 29★, `qvr` 25★, `agentpack` 16★ and `grimoire` 15★.
- **ToDo:** the interface is Chinese only. `FlowBoard` (96★) and `delegatus` (36★) are the same shape, and `claude agents` already shows which agents are waiting on you.
- **gboard-openai-dictation:** it requires patching and building Gboard yourself. `DictateKeyboard` (316★) and `dictus-android` (28★, offline) give you phone dictation without that.
- **Family Finances:** the parsers target Brazilian banks, and `docs/projects/` already has 22 unbuilt finance plans. One idea is worth borrowing for any of them: it checks each import against the total printed by the bank, which catches parser errors without a human reading every row.

Three more repos were left out of the table: `sooftware/lmux` (macOS only), `SunSinD/Sunlith` (an Android calendar controlled over MCP, while the Google Calendar connector is already available here), and `ederheisler/skills-manager` (needs Node 26, while `/skill-doctor` and `ccplug` cover most of it).

## First-Party News

**[Personal Finance in Claude](https://claude.com/resources/articles/introducing-personal-finance-in-claude) was announced on 2026-11-05.** You connect bank and card accounts read-only and ask questions in plain language, and it can flag double charges, fees and bills that have crept up. The beta is limited to Pro, Max and Ultra plans in the US, so it doesn't replace anything here yet. Any finance candidate or backlog plan built around US bank connections now competes with it. Plans built on Indian SMS or statement parsing aren't affected for now.

## Worth Doing Instead

**Add a delete guard to the unattended jobs.** They run with permission checks off, and a hook still applies in that mode according to the README of `claude-code-recursive-delete-guard`. Read the single Python file first, then add its `PreToolUse` entry by hand. Don't run its `--install`: that rewrites `~/.claude/settings.json`, which holds a live token inside the hook commands. I haven't tested this hook.

**If morning usage limits are a problem, move the window with one crontab line** rather than a tool. The time below is only an example:

```
30 8 * * 1-6 /home/sibin/.local/bin/claude -p hi --model haiku >/dev/null 2>&1
```

The idea that the 5-hour window starts at your first message comes from these projects' READMEs, and I haven't confirmed it in Anthropic's docs. The 01:00 and 01:33 discovery jobs use the account overnight, but `olx-finder` at 06:00 doesn't call `claude` directly, so nothing scheduled sets the window for your morning. Scheduled cloud tasks draw down the same subscription usage, according to the routines docs.
