- **One viable, breaking a seven-of-nine zero-viable streak (08-19, 08-29, 08-31, 09-03, 09-04, 09-06, 09-07).** Fourteen candidates screened, thirteen killed. The survivor did not survive because the bar moved; it survived because it is the first thesis in weeks whose novelty claim held up under the 08-18 prior-art rule after three rounds of broadened phrasing.

- **Why `sarika-voice`'s novelty survived when nothing else's did.** The usual death is "search the thesis, find a 5000★ incumbent." Here the search found the opposite: [github/copilot-cli#3806](https://github.com/github/copilot-cli/issues/3806) is an **open, unshipped feature request** on the market-leading agent CLI asking for exactly this — a dictation dictionary auto-seeded from the repo. The only direct implementation found anywhere was `dimastatz/whisper-code` (0★, VS Code-only). When the incumbent has filed the problem against itself and not shipped it, `novel = 1` is evidence-backed rather than a failure to search hard enough. The technique is also research-validated but unproductized (arXiv 2410.18363 and 2502.11572 on contextual biasing of Whisper; arXiv 2601.15339 measuring how ASR errors specifically wreck code identifiers).

- **The candidate repo is a stub, and that is fine.** `lvampa/sarika-voice` has 0★ and its default branch is `worktree-sarika-phase1-walking-skeleton`. The plan logged today is for building the thesis, not installing the repo. This is the intended use of a 0★ same-day find: the idea is validated, the code is not.

- **The dictation lane exploded this week and it did not threaten the finding.** Seven local-dictation repos were created in the same 48 hours (`whisperkey`, `IrisFlow`, `my-local-whisper`, `vlocal`, `WhisperType-Android`, `unmuddle`, `voice-to-clipboard`). A crowded lane solving an adjacent problem is not prior art for this one — worth stating explicitly, because the raw repo count would otherwise have scored `novel = 0` on reflex.
