## Why Each One Stopped

- **satori:** the most interesting find today, and it's something to install, not build. It runs fully offline on Android: Parakeet and AI4Bharat IndicConformer for speech, Gemma 3 1B / Qwen 3.5 0.8B through a patched `llama.cpp` for note writing and to-do extraction, and IndicTrans2 for a Malayalam → English reading pass. Prior-art searches (`malayalam speech offline`, `malayalam transcribe`) found only 0–1★ repos, so it scores novel. It fails as a build: it's native Kotlin with three on-device model stacks, far too much for a weekend. The planner already has 8 unbuilt voice plans and 12 unbuilt journal plans, and this repo covers the voice-diary one (`voxdiary-flutter`). If you dictate in Malayalam, sideload it (arm64, Android 10+) before writing plan #9.
- **Budget Widget:** also an install. It has no INTERNET permission and no AI, and its v1 parser lists Federal, Kotak, Jupiter, slice, Axis, SBI and HDFC. It's early (milestone M2: categories, with notifications and widgets still to come). The Indian-SMS-parsing lane is 61 repos deep and the planner holds 19 unbuilt finance plans, so a build scores `fills_gap=0` and `novel=0`. Watch for its M8 release instead.
- **bekci:** a zero-dependency `npx` scanner with no network access that reads user-level and project agent config for hidden Unicode instructions, credential theft, typosquatted MCP servers and "lethal trifecta" setups. It fills a real gap here (dozens of enabled plugins and skills, plus custom hooks), but the scanner lane already exists: `skillhawk` (70★), `agent-audit` (17★), `skillguard` ×2, `agentvet`, `agent-config-doctor`, plus the prompt-injection hook lane (55 repos). See *Worth Doing Instead*.
- **Aye:** a nice design (Web Push → passkey-signed approve, with a 60-second fallback to the normal prompt), but phone approval for sudo is an 8-repo lane (`UnTouchID` 343★, `sudo-approve`, `Approven`, `sudostamp`, `chris-tse/sudo-request`). For Claude Code prompts, Remote Control already reaches the phone. Nothing here needs sudo approvals daily.
- **Codesk:** a desk of windows (app preview, token use, even solitaire) that you reshape by asking the agent, over the Agent Client Protocol. It's new: `agent reshape ui desktop` returned 0 hits. But it's a large build, and the agent-UI lane plus first-party `claude agents` and the desktop Code tab cover daily use here.
- **lmsk:** the local secret/PII masking lane was 12 repos deep on 09-06 and has grown (`cloakroom`, `latet`, `Veil`, `keepmum`, `shim-cli` 40★; 37 hits for `secret mask claude code`).
- **lot-map:** a trace-pane mod. That lane was already marked automatic `novel=0` on 11-06; `Agent-Blackbox` (83★) and `atalay-terminal` (21★) draw the same live map.
- **wilfred:** a session-status board for the Claude desktop app on macOS. First-party agents view (`claude agents`, peek panel, the "waiting on you" count) killed this lane on 10-18.
- **claude-model-router:** `musistudio/claude-code-router` (38,085★) owns routing. Inside Claude Code, subagent `model:` frontmatter and the `opusplan` alias already pick a model per task.
- **mcp-patchbay:** this harness already defers MCP tool schemas behind `ToolSearch`, so toggling servers mid-session saves little here. `mcpick` (98★) and three GUI toggles already do the switching.

## First-Party News

**2.1.321 tightens the email check, but the email still isn't removed from context.** The [changelog](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) now goes up to 2.1.322. 2.1.317 added a check that asks before a web or shell call sends your account email. 2.1.321 changed it to silently refuse only a shell command that holds the email *and* names a User-Agent, so scheduled runs no longer stop at that prompt. This box is still on **2.1.311**, which has neither.

**2.1.321 also has two security fixes worth the update:** MCP OAuth requests could send refresh tokens to another host when a server redirected them, and a read-only Bash command could run outside the sandbox without a permission prompt. It also makes Claude Fable 5.2 the default Fable model.

## Worth Doing Instead

1. **Update Claude Code from 2.1.311 to at least 2.1.321.** This picks up the email check, the MCP OAuth redirect fix and the sandbox fix in one step, and it matters most for the two nightly `claude -p` cron jobs.
2. **Run `bekci` once, read-only, instead of building a config scanner.** `npx` isn't on the default PATH here, so use `PATH="$HOME/.nvm/versions/node/v24.14.0/bin:$PATH" npx bekci`. It claims zero dependencies and no network access. Check both in its `package.json` before running it, because `~/.claude/settings.json` holds a live token inside the hook commands. Keep the report local and don't paste it anywhere.
