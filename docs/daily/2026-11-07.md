## Why Each One Stopped

- **ifinjected:** the closest call today, and the novel score decides it. The gap is real here because the unattended jobs run with `--dangerously-skip-permissions`, and the tools I found only partly overlap: `Pringled/agentcheck` (28★, inactive since March) covers credentials, `agentconfig-doctor` (13★) covers risky config and `trifecta-gate` (0★) includes a lethal-trifecta scanner. But `uvx ifinjected` already does the whole job, so building another one would only copy it. You'd also run an audit like this occasionally, not daily. See below.
- **Zemzeme:** `linux dictation` returns 930 repos, led by `OpenWhispr` (10,879★), `hex` (5,491★) and `voxtype` (1,746★). Its useful angle is that transcription happens in the cloud, which suits this box with no GPU, but `ostt` (315★) already lets you pick a provider. This is something to install, not build.
- **OpenFinances:** it has no AI, and its bank parsing and calendars target Persian users. `docs/projects/` already has about two dozen finance plans, and `Moneyprism` and `Aspend` (25★) already cover Flutter SMS parsing for Android. One idea is worth borrowing: leaving out the internet permission makes "your data stays on the phone" something the OS enforces, not just a promise.
- **setupscore:** `HudsonGri/mdarena` (68★, April) has the same pitch, "Benchmark your CLAUDE.md against your own PRs", and `skillcheck` (30★) does blind A/B tests. `/doctor prompt-audit` and the enabled `claude-md-improver` skill already cover the static checks. The benchmark also uses API credit or subscription usage on every run, so it's not a daily tool.
- **coban:** `agent-of-empires` (3,659★) and `cli-agent-orchestrator` (1,520★) lead this lane, and `maestro` and `claude-code-orchestrator` already route work across accounts. Subagents and `claude agents` cover the need here.
- **rex-inbox:** Rex isn't installed on this box, and `claude agents` already shows which agents are waiting on you. Its README credits the idea to Plannotator's Inbox.
- **claude-workflow-kit:** `claude code token saving` returns 138 repos, and `ponytail`, `ccplug` and `/skill-doctor` are already set up here. Its guide does make one claim worth a look: in three days of one designer's logs, 84% of the cost was reading context. That's a single person's data, and I didn't check it.
- **dictation-lab:** the idea is uncommon, with only `VoiceRefine` (0★) close to it. But it reads a Mac app's recordings and trains with MLX, so it can't run on this Linux box. It also needs a daily dictation habit first, the same blocker as yesterday's `ASR Recursive Improvement Loop`.
- **rexc:** it needs Rex, which isn't installed here. `rexpocket` (25★, 10-29) is the same app and `whip` (124★) does this for Herdr. Remote Control already gives you your sessions on your phone.
- **Voice foreman:** speech runs on a local GPU and this box has none (`nvidia-smi` isn't installed). `call-me` (2,672★) and `claude-phone` (343★) already own the lane.

Five more were left out of the table: `wolfmem` (session memory, a saturated lane), `terminal-aide` (plain English to Bash, a lane with long-established tools such as `zsh_codex`), `agent-voice` (needs the closed-source Vois Studio), `flawless-ui-ux` (33★, while `frontend-design` and `design-taste-frontend` are already installed) and `pixel-buddy` (a pet, not a tool). `Monetor` and `Liner Notes` are iPhone-only apps, so they were dropped too.

## First-Party News

**[Claude Code can put your account email in web request headers](https://github.com/anthropics/claude-code/issues/107757).** This was today's biggest AI story on [Hacker News](https://news.ycombinator.com/item?id=50385272), at over 1,500 points, and the issue is still open.

- **Cause:** according to [this explainer](https://theainewsreport.com/2026-11-06-claude-code-email-user-agent-leak-privacy-mod-explained.html), the model was given your email and sometimes used it as the contact in a `User-Agent` when writing its own `curl` calls or scripts.
- **Fix:** the same explainer reports that Anthropic plans to remove the email from the model's context in a release expected early next week. I couldn't confirm that from Anthropic directly.
- **Stopgap:** the [changelog](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) for 2.1.317 adds a check before a web or shell call sends your email. The explainer says it misses scripts written to disk and web tools, and that some users saw it fail to fire.
- **This box:** it runs **2.1.311**, which predates that check. I scanned all 2,941 local transcripts, which go back to 2026-08-31, and found **no** email in a `User-Agent` or `curl -A`. That scan can't see addresses read at run time, or anything from sessions already deleted.

**[A Claude Dispatch flaw remains unfixed](https://www.theregister.com/research/2026/11/05/anthropic-wont-fix-a-claude-dispatch-flaw-that-could-let-attackers-execute-remote-commands-across-corporate-boundaries/5307684), according to The Register.** A browser extension that can control claude.ai could send commands to Claude Desktop through Dispatch. The researcher says the same weakness carries over to Remote Control and Cowork. Anthropic didn't respond to The Register's questions. I only read the report and didn't test this.

## Worth Doing Instead

**Update Claude Code once the release that removes the email ships.** Nothing needs blocking today, going by the scan above. This nightly job is the one to watch: it runs on 2.1.311 with permission checks off, and the model writes `curl` calls to many hosts. Run the scan again after the next few nightly runs, or once the fix ships.

**Run `uvx ifinjected` once, on this box.** This is the one to try from today's list, since the unattended jobs skip permission checks. Its README says it's read-only and offline, and never reads credential values. I haven't run it, so read the source first. Don't share its output or share card, because it reads agent config and `~/.claude/settings.json` holds a live token inside the hook commands.
