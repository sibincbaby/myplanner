## Screening Notes

- **Zero viable today — every 3+ draft died to the same two checks, and both checks are ones this pipeline has run before.** No project cleared the bar; the two closest calls are broken out below because the *reasons* they died are worth keeping.
- **LEGER_OS looked like the best find of the day and the prior-art check killed it in one query.** "Zero-credential" personal finance via an Android `NotificationListenerService` that regex-parses bank/UPI/wallet push notifications in-memory, no Plaid, no bank login — genuinely clever framing, and it fits two interest areas (finance + Flutter/mobile) at once. It scored a provisional 3/4 (weekend_buildable=1, fills_gap=1, daily_utility=1) until `gh api search/repositories -f q="sms expense parser android"` came back with **eleven** near-identical repos: `Moneyprism` (Flutter, 50+ Indian banks, 100+ UPI handles), `TruXpense` (Kotlin, Gemini-categorized), `allwin-antony/Expense_tracker` (on-device FastText, blocks loan spam), `knom` (Flutter, SMS-parsing, zero manual entry) among others. SMS/notification-parsing expense tracking is not a gap in this ecosystem, it is a genre — this repo's own backlog already lists fourteen unbuilt finance plans for the same underlying reason. `novel` drops to 0, total drops to 2/4.
- **config-drift-checker is the second-best find, and the right move is to install it, not clone it.** It is a complete, already-shipping Claude Code plugin that turns `CLAUDE.md` + skills + hooks into `claude plugin eval` test cases, runs them on every Claude Code release and every PR that touches the setup, and diffs against a baseline — "CI for your agent setup." This is close to a direct answer to the chronic problem documented across two dozen runs of *this exact pipeline*: `read-seen` silently returning `"[]"`, `write-digest` making zero tool calls and echoing injected guidelines instead of writing a file, `derive-date` returning the literal string `date +%F` instead of running it. A regression suite that runs on every Claude Code release would have caught several of those the day they happened instead of a day (or four) later. It scores 2/4 as a *build* candidate (`weekend_buildable=0` because there's nothing left to build — it's a two-command install) but it is worth acting on directly: `claude plugin marketplace add jameskomo/config-drift-checker` in this repo, seeded with eval cases for exactly the three failure modes in `state/`'s memory notes.
- **Two more died on saturation, not on execution quality.** `Income-Expense-Tracker` (Claude-powered categorization + receipt OCR) and `ChawFi` (natural-language budget tracking) are both competent, both `fills_gap=0` — the same fourteen-plans-zero-shipped finance-lane verdict from 08-19 still holds, and today's sweep (`budget`, `finance-ai`, `expense-tracker`) surfaced nothing that breaks the pattern. `tokentab` (Claude/Codex/Gemini cost-by-project-by-day) is the fifteenth entry in the usage-tracker lane flagged saturated on 08-23 — `phuryn/claude-usage` (2182★), `Clawdmeter` (2117★), `claude-swap` (2028★) and a dozen more already do this.
- **agentctl and Product-to-Prod both score `fills_gap=0` for a narrower reason: they solve a problem this specific user doesn't have.** `agentctl` unifies agent-harness config across OpenCode/Agy/Claude Code/Codex — this box only runs Claude Code, so there's nothing to unify. `Product-to-Prod` is a full PM suite (PRDs, RICE scoring, GTM launch plans, roadmap tooling) built for teams shipping products to other people, not a solo indie-hacker's daily loop. `Only-Skill-You-Need` (bootstrap + auto-route to the best skill) scores `fills_gap=0` for the same reason `agent-codemode` did on 08-19 — the platform, via `superpowers-extended-cc:using-superpowers`, already does exactly this in the session that would evaluate the candidate.
