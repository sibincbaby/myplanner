## Viable Projects

- **[Clayrune — Mission Control Dashboard for Parallel Claude Code Agents](../projects/2026-09-25-clayrune-mission-control-for-parallel-claude-code-agents.md)** — The scheduler + NEEDS YOU interrupt model is what separates this from the prior cockpit/fleet plans. Running agents fire until they need a human decision; the dashboard catches that signal and surfaces it. The stack is minimal (Flask + JSON, no database), so a working single-project version is an evening build. Novel: prior fleet plans tracked agent status; this adds a cron-style scheduler and cross-session memory so the agent system learns from past runs. The lane is crowded (claude-fleet, agentmux, cockpit, agent-deck) but none of those shipped a scheduler with a per-session memory store.

- **[Breadcrumbs — Repo-Local Decision Memory for Coding Agents](../projects/2026-09-25-breadcrumbs-repo-local-decision-memory-for-coding-agents.md)** — Every other memory plan stores context globally (per-user or per-project in an external store). Breadcrumbs stores it in the repo itself — plain Markdown committed to git — which means the decision log travels with the code it explains, survives tool switches, and is visible to any reviewer. The entire MVP is a session-end skill that writes one file and a session-start hook that injects the last few entries. Phase 1-3 is under an hour. What makes it novel: it captures *why* (architectural decisions, failed approaches, gotchas) not just what, and it is agent-agnostic because it is just a folder of files.

- **[Personal Finance Skill — Plaid + Alpaca + IBKR for AI Agents](../projects/2026-09-25-personal-finance-skill-plaid-alpaca-ibkr-for-ai-agents.md)** — The lane is crowded and tomfunk/fungible (108★, TUI + GUI, Plaid sync, CSV import, AI assistant, MCP server) is the standing superset kill for personal finance tools. What keeps this alive: the trading layer. Fungible is an expense tracker with some AI; this skill connects Alpaca paper/live trading and IBKR portfolio data, meaning a single `/portfolio` command surfaces real brokerage positions alongside bank spending. The tax optimization layer (23 tools) goes beyond categorization into estimated quarterly liability. Daily utility is the weak leg — finance queries are weekly not daily — but the Plaid transaction queries ("did any subscriptions renew this week?") are close to daily. Viable but narrowly.
