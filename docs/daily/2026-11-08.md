## Why Each One Stopped

- **openGPUI:** today's closest call, and the only one that's new. It ports all 86 components of `thesysdev/openui` (14,919★) into a [Herdr](https://herdr.dev) pane. The agent writes a short file, and you see tables, charts and forms and click your answer back. None of my searches found another tool that draws generated UI in a terminal pane, so it scores novel. It fails on fit: Herdr isn't installed here, and `AskUserQuestion` (first-party) already shows choice cards. Claude Code mods can also draw above the prompt, and `MCP-UI` (5,254★) covers rich UI in clients that support it. Keep an eye on it in case it moves off Herdr.
- **mike:** an alpha Rust proxy that records sessions so you can open any turn in a browser. This is a crowded lane: `claude-tap` (3,328★) intercepts the same traffic, and `claude-devtools` (4,022★), `cost-xray` (5,809★) and `claude-code-trace` (385★) already let you inspect sessions. Its other feature, turning a correction into something the next session starts with, is what `pro-workflow` (2,946★) and `claude-reflect` (1,923★) already do.
- **ProcLease:** since 2.1.282, background Bash stops on its own after a time limit (30 minutes by default), which is a built-in lease. The leftover-process lane already had 8 repos (`Agentinel` 50★ and others). Its one new rule is that reading logs never extends the lease. That's tidy, but too small to build on.
- **agentcheckup:** `/context`, `/skill-doctor` and `/doctor` already cover context cost and config here. This harness also defers MCP tool schemas behind `ToolSearch`, so the per-request tool cost it measures is mostly not paid on this box. `agentconfig-doctor` (13★) was in yesterday's notes with the same pitch.
- **baton:** the failover lane already has `agentswap` (08-15, Claude Code and Codex across subscriptions and API keys), `agent-router` (06-15, the exact pitch) and `subrouter` (122★). It only helps with several vendor plans, and its Claude leg is the paid API.
- **Harness Relay:** `Audatic07/duo` (25★, 10-02) is a desktop app that puts Claude Code and Codex in one chat, with debates and councils. `botference` (20★) and `council-of-high-intelligence` (4,807★) do the same deliberation. A three-vendor debate isn't something you'd run every day.
- **plan-tool:** the enabled `superpowers-extended-cc` plugin already writes plans and runs them (`writing-plans`, `executing-plans`), and `plannotator` (9,848★) owns plan review.
- **claude-p-pipeline:** a 26-chapter Chinese tutorial with a small chat app to run. The self-hosted "chat with Claude Code from a browser" lane is crowded (`claude-chat-mobile` 54★, `heyhank` 34★, `paddock`, `PocketClot`), and Remote Control already gives you the real session on the phone. The 44 stars on day one don't say much about quality.
- **Seti:** `nithiink/yapcode` (16★, 05-24) has the same pitch: "One voice agent to control all your Claude Code sessions — from your browser or phone". Remote Control covers the phone side. Voice, sandboxes and a swarm view together are too much for a weekend.
- **tinker-ai-skill:** training runs on Thinking Machines' hosted Tinker service, which needs an account and costs money per run. `Amanlabh/footprint` (18★, 07-12) already fine-tunes a small model on Claude Code sessions. It's a one-off experiment, not a daily tool.

## First-Party News

**The email fix hasn't shipped yet.** The [changelog](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) now goes up to 2.1.319, and neither 2.1.318 nor 2.1.319 mentions removing the account email from context. This box is still on **2.1.311**. Yesterday's item stands: update once that release lands.

**2.1.319 adds `permissions.denyInsteadOfPrompting`.** When a tool call would wait on a permission prompt, it is denied and the turn continues instead, in terminal sessions, subagents and teammates. For headless `claude -p` runs like the nightly jobs here, the older `--permission-prompts none` flag (2.1.259) already does this, and this box's 2.1.311 has it.

## Worth Doing Instead

**Try the nightly jobs without `--dangerously-skip-permissions`.** This box's version already has what's needed. Give `--allowedTools` the tools a discovery run uses: `Read`, `Write` and `Edit`, plus Bash for `gh api`, `curl` (to `hn.algolia.com` and `raw.githubusercontent.com`), `git` and `python3`. Then add `--permission-prompts none`, so anything outside the list is refused instead of hanging the job. Check the first night's log for refused calls before trusting it. I haven't tested this.
