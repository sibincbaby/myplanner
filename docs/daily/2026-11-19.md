## Scoring Notes

- **cache-maxxing** (2/4): this is something to install, not to build. It reads numbers Claude Code already tracks and works in the terminal, VS Code and the desktop app. DU=0 because this account runs a 1-hour prompt-cache TTL, so in a working session the bar stays green almost all the time. It only matters after a long break, and `/cmaxx-handoff` overlaps native `/compact`. It also falls in the "renders a usage number" lane, which is saturated.
- **Terminess** (0/4): Swift on macOS 14+ with an iPhone app, while the user is on Linux. Remote/mobile access to Claude Code is covered first-party by Remote Control, and the "terminal session shown as chat" view already exists in several tools.
- **Pocket Book** (2/4): it has no LLM; the parsing is rule-based. Spreading a monthly budget into a per-day allowance is already in Cashew/CutMyCost (`~/my-works/Cashew`, `~/my-works/cutmycost`), and PesaPilot already does natural-language capture. If anything, the one-line batch syntax is a small PesaPilot feature, not a project.
- **Raizen** (2/4): this is the same lane as the `SwashBuckler104/budget-widget` install row and the 11-18 `expenditures-control` plan. Treat it as one more install option for Indian bank-SMS parsing. Its "on-device AI" is not backed up in the README beyond the parser claims.
- **session-skill-audit** (1/4): FG=0 under the already-enabled-plugin kill class, because `claude-md-management:revise-claude-md` is enabled here. The corrections→memory lane is also saturated (`claude-reflect`, `pro-workflow`).
- **Flagman** (1/4): Claude Code's native task list with `blockedBy` dependencies and the Workflow tool already cover multi-session task graphs. A live page only helps on large fan-out tasks, which the user doesn't run every day.
- **My Board** (2/4): a full Android IME is not a weekend build, and AI keyboards are a crowded category. Worth trying as an install. Privacy note: it sends on-screen chat context to an LLM to draft replies.
- **xcontrol** (2/4): tmux agent groups and agent-to-agent messaging are both saturated lanes (yesterday's `Pulsar`, plus native `@`-mentioning of other sessions since 2.1.232).
- **Goldcrest** (1/4): closed SaaS (Toronto, TFSA/RRSP-shaped). Prior art kills it: `saferonline-co/agentic-financial-planner` (conversational lifetime plan in Claude Code with a deterministic engine), `zubair-trabzada/ai-finance-claude` (89★), plus our own `2026-08-05-financial-planning-agent` and `2026-10-05-finlynq-personal-finance-fire-mcp` plans.
- **cmdbook** (2/4): closed-source and paid. The lane is covered by `navi`, `pet`, `just` and Raycast script commands, and the user's skills and CLIs (`lwdb` templates, `csess`, `ccplug`) already fill the "commands an agent can run" role.
