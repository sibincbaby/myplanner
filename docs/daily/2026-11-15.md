## Scoring Notes

- **facetshot** (2/4): The "contact sheet" idea (devices as rows, light/dark/large-text as columns, plus console logs and an overflow check) has no direct match across web, Storybook, Electron, Tauri and SwiftUI, so N=1. On this box it doesn't help much: its own status table lists Linux as "expected, untested" and Flutter as web-only. The Flutter version of this idea was the day's best lead, and it's already built: `youssef336/flutter_screenshot_matrix` (10-12, MIT, on pub.dev) renders devices × locales × themes × text scales headlessly inside `flutter test` with no emulator, loads real fonts, records overflows with the source line, and writes an HTML gallery. `marionette_mcp` (505★) covers the running-app side. FG=0.
- **llm_outbox** (2/4): A real gap in the Dart ecosystem. Prior-art searches (`llm offline queue flutter`, `dart llm retry persistence`) return only this repo. It's MIT and already on pub.dev, so it's a dependency to add, not a project to build (N=0). It's useful whenever one of the Flutter AI plans gets built, not every day.
- **AI Time Estimator** (2/4): It has Claude count the work, then times it with rates measured from your own sessions and scores itself after each task. That would make the "Effort" lines in this repo's plan docs measurable instead of guessed (FG=1). It's polished (CI, releases, plugin marketplace), and `ecappa/web-dev-estimation` (03-18) has the same pitch, so N=0. Not daily.
- **flutter-senior-review** (2/4): Would fire on every Flutter edit, so DU=1. But the Flutter agent-skill lane is 6+ deep (`agent-skills-standard` 562★, `ducafecat/skills`, `flutter-clean-arch-skills`, `ui-craft`), and the local `flutter-forge` skill already covers the workflow.
- **likhari-ai** (2/4): Cross-platform, so it runs on Linux, which most dictation entrants don't. Still, it's another entry in the most saturated lane in this log (OpenWhispr 5.8k★ and others, `awesome-voice-typing`, plus 8+ unbuilt voice plans here). The sweep found 20+ new dictation repos in 48h.
- **sketch** (1/4): A well-made mod with 17 drawing tools, but the lane is 6 deep: `prismantis` 399★, `cc-intelligent-ui` 157★, `merman` 51★, `codechart`, `claude-code-figures-plugin` (kitty graphics). The local `dataviz` skill covers charts.
- **KittyBrowser** (1/4): Prior art is older and bigger: `termium` 213★ (2024), `casty` 54★, `termweb`, `bytehunt/br` (agent browser with kitty rendering). For agent browsing, Claude-in-Chrome and the Playwright/Chrome DevTools MCPs already exist.
- **claude-sessions** (1/4): The session-restore lane is closed: `tabkeep`, `undead-ai-sessions`, `wezterm-session-restore`, `hex/claude-sessions` (same name, seen earlier), plus first-party `--resume`/`--continue` and the local `csess` skill. It does repeat a point worth acting on: `cleanupPeriodDays` is still unset here, so transcripts are deleted after 30 days.
- **Rulebook** (1/4): macOS-only Swift app. `/doctor prompt-audit` and the enabled `claude-md-management` plugin already audit CLAUDE.md files.
- **Blew OS** (1/4): The forecast engine (`lib/finance/forecast.ts`) is worth reading. It treats an entry as recurring when the same description appears in 3+ months with amounts within 15% and day-of-month within 4, and it fits a weekday baseline with an 80% band. It's built for agencies, not personal use, it's a large app, and the planner already has 22 unbuilt finance plans (backlog rule → FG=0).

## Worth Trying Instead of Building

- **flutter_screenshot_matrix**: add it as a dev dependency to the next Flutter app and have the agent read `screenshots/index.html` (red overflow badges) after UI changes. This works on Linux with no emulator.
- **llm_outbox**: use it as the persistence layer when building any of the Flutter AI plans (offline voice journal, SMS expense) instead of hand-rolling retries.
- **AI Time Estimator**: `/plugin install ai-time-estimator --marketplace noambrand/ai-time-estimator` if you want measured "AI minutes" in place of guessed effort estimates.
- **Blew OS**: borrow the recurring-detection rule above for the finance MCP plans.
