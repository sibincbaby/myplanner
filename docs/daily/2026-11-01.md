## Why each died (and why four didn't)

- **stock-market-mcp (viable, install-first):** 130 tools covering SEC 13F filings, congressional and insider trades, options chains, FRED macro, earnings call transcripts, live quotes, IPO listings. The finance backlog has expense/budget trackers but nothing giving Claude access to live market instruments. Free plan is 100 req/day — enough for daily portfolio checks. WB=0 because there's nothing to build; this is a 15-minute install. The scope is large enough that using it daily is likely: "show me which ETFs congress bought this week" is exactly the kind of query that would otherwise require a browser session.
- **optio (viable, install-first):** Full CI→review→merge loop orchestration for Claude Code, Codex, Copilot, Gemini, and OpenCode. It polls PRs every 30s for CI status and review state, resumes the agent with context on CI failures or "changes requested", and squash-merges when ready. WB=0 (Kubernetes/Helm deployment is heavyweight for a weekend) but FG=1 (no tool in current setup auto-drives a PR from issue creation to merge), N=1 (auto-close loop from first commit to merge is different from all the multi-agent UIs seen), DU=1 (every project sprint).
- **j0nl1/open-finance (viable, build-first):** Local MCP server that lets Claude ask your bank for balances, transactions, and spending data without it leaving your machine. The strongest gap in the personal finance coverage: all seen tools (Monarch MCP, copilot-money-mcp, accountant24, expense-mcp-server) either require cloud signup or track expenses you enter manually. This one is data-at-source.
- **chetto1983/broker-analysis-mcp (viable, install-first):** Yahoo Finance MCP packaged as a Claude Code plugin with five pre-built skills: sector analysis, portfolio metrics, P/E ratio comparisons, earnings calendar, dividend tracking. Prototype status, so expect rough edges; the fit here is evaluation + extend, not production use. DU=0 because active trading isn't daily, but the install cost is near-zero.
- **obra/superpowers:** 284k stars, published February 2026, re-surfaced on trending Oct 28. N=0 disqualifies it as a "new discovery." That said: it's not in the backlog. If the TDD skill loop isn't already running here, `/plugin install superpowers@claude-plugins-official` is the install, zero sessions needed.
- **drobertson-dev/agent-studio:** Scored 4/4 on viability criteria but v0.1.2 shipped in June 2026 — outside the 48h window. Flagged for a follow-up fresh look; the self-hosted AI app studio concept (Next.js + Rust API, Docker Compose, build mini-apps with agents) is genuinely gap-filling if it's still actively maintained.
- **nima54851/agent-studio:** FG=0 (this user already runs a daily discovery routine), N=0 (generic developer toolkit pattern), DU=0 (one-time setup). Skip.
- **anthropics/financial-services:** Official Anthropic repo of financial Claude Code plugins. N=0 (polished official product), WB=0 (not for building — just install). Worth installing `financial-analysis` from that marketplace, but not a plan to write.
- **finometr-com/finometr-claude-plugin:** Just a wrapper pointing Claude Code at the Finometr hosted MCP server. No local option, no free tier mentioned. SME cash-flow focus doesn't match personal finance interests here.
