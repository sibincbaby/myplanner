## Viable Projects

- **[dots: AI agent with patched Firefox browser](../projects/2026-10-05-dots-ai-agent-patched-firefox-browser.md)** — dots patches Firefox at the C++ level to remove every anti-bot signal: no WebDriver flag, no DevTools protocol exposure, trusted pointer/key events, consistent fingerprint per seed. The result is a web agent that doesn't fail at the browser layer — flight trackers, social feeds, paywalls — and gets invoked with `uvx` + an OpenRouter key. The weekend build doesn't need the C++ patches; it uses Playwright-extra + stealth plugin, which covers 90% of real-world sites, plus a local chat at `localhost:8765`. Stack: Python + playwright-extra + playwright-stealth + FastAPI + Anthropic SDK. 2 sessions to a working research agent CLI with session persistence.

- **[LUCI Desktop: ambient screen memory for AI agents](../projects/2026-10-05-luci-desktop-ambient-screen-memory-agents.md)** — LUCI records your screen and meetings, turns them into a searchable local store, and exposes an MCP server so Claude Code, Codex, and Cursor can query what you were doing across sessions. The commercial app (Mac + Windows, free) is polished, but the personal build is worth doing: you control the capture rate, the index format, and which sessions are indexed. Stack: Node.js + screenshot-desktop + Claude Haiku (screenshot descriptions) + SQLite FTS5 + MCP SDK. 2 sessions to an always-on daemon with `search_memory`, `recent_context`, and `session_timeline` MCP tools registered in `~/.claude/settings.json`.

- **[CopilotKit/OpenDots: persistent AI agent workspace](../projects/2026-10-05-opendots-persistent-agent-workspace.md)** — OpenDots is a TypeScript/Next.js template (MIT, 3.2k stars, Alpha) for always-on AI coworkers that persist across sessions, take voice calls, and post to Slack. The gap vs Claude Code: Claude Code sessions are ephemeral and single-task; an OpenDots "Dot" accumulates context, remembers prior sessions, and can be reached by Slack message. MVP: fork + local deploy + 2 specialized Dots (ResearchDot with web search context, FinanceDot wired to the finlynq MCP). 1-2 sessions to a running personal workspace.

- **[finlynq: personal finance planning with FIRE/Monte Carlo MCP](../projects/2026-10-05-finlynq-personal-finance-fire-mcp.md)** — Finlynq is distinct from MyFinance MCP (Oct 4, expense tracking + 28 tools) in scope: it's a full financial planning tool — budgets, portfolio, goals, loans, FIRE number, Monte Carlo simulation — with 90 MCP tools and an Anthropic Connectors Directory listing. AGPL, self-hostable via Docker, AES-256 at-rest encryption. MVP: `docker compose up`, import historical bank CSV, wire to Claude Desktop. The value unlock is asking "how far am I from my FIRE number?" directly in Claude chat, with live Monte Carlo behind it.
