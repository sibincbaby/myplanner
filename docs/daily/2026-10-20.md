## Why each died

- **OmniRoute**: The multi-provider fallback gateway is a real pattern, but the gap is already filled by LiteLLM (which is far more polished, has 70k+ stars, and covers every provider OmniRoute does plus more). WB = 0: standing up a gateway with 237 provider configurations is not a 1-session project from scratch. N = 0: LiteLLM is the established OSS standard for this. Install `litellm --proxy` instead; no new build needed.

- **jev-ultrafast**: An interesting approach — replacing screenshot-based vision with a structured element table — but FG = 0 and DU = 0. Browser agent automation is already well covered in this toolkit by `browser-use` (20k+★) and Playwright MCP servers. jev-ultrafast is a benchmark-optimised variant of browser-use, not a new category. WB = 0: implementing an indexed-action-space browser loop from scratch requires significant engineering.

- **GenAI Expense Tracker MCP**: Expense tracking via Claude MCP is well covered in the seen list already: `bubbletroubles/actual-budget-mcp`, `CSOAI-ORG/personal-finance-ai-mcp`, and `DoganayBalaban/finance-mcp` were all screened in prior cycles. FG = 0: three nearly identical tools have already been evaluated; the slot is occupied. N = 0: this is a straightforward FastMCP + SQLite port of the same idea.

- **Pancake**: Claimed to be "Vercel for GTM" with a Claude/Codex MCP connection. No GitHub repo found, website is behind a waitlist, no documentation of what the MCP server exposes. All four criteria zero: can't build it, can't verify the gap, can't assess novelty, unclear if daily utility. Skip until it ships publicly.

## Notes

- **GitHub trending today** (Oct 20) had no AI/agent entries in the top 25 — mostly OSS emulators, self-hosted media servers, and system tools. Discovery leaned on roundup blogs, Product Hunt Oct 14–19 leaderboards, and GitHub topic searches.
- **OpenRig** (`anomalyco-adjacent` harness from Oct 13 digest) and **Shadok** (parallel agent cockpit, Oct 13 digest) both covered the multi-agent parallel coding idea. Orca (stablyai) is distinct: it's more mature (65k★), MIT-licensed, ships a mobile companion app, and explicitly supports comparing diffs from multiple agent runs before merging. Worth covering despite the similar concept.
- **context-mode** (`mksglu/context-mode`, ~30k★) keeps appearing in roundups as a highly recommended token-compression plugin for Claude Code. Seen Oct 16, Oct 18, Oct 19 — not re-adding to seen list. Install with: `claude mcp add context-mode -- npx -y context-mode`.
- **Claude Code v2.1.302** reportedly shipped Oct 17 with an official plugin system. The core SDK changes are in the anthropics/claude-code changelog; no new user-space tool to discover here.
