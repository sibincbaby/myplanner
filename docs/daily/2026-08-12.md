## Screening Notes

- **Remarc is the find of the day because of its lifecycle, not its input methods.** Voice is the most saturated area in this backlog — vocalmcp, voxctrl, voicecode, localmic, voxdiary-flutter, echocode, haraduo and speakoflow all cover capture. What none of them have is a *comment that stays open until the agent closes it*. Remarc's shape is point → annotate → the agent pulls the open set over MCP → resolves → the comment closes. ContextPop (07-26) captures context into a task and stops; Sightline (07-25) and UIVerify (08-01) are agent-driven inspection with no human annotation channel. The review loop is the novel part and it is what makes the daily-utility score honest.
- **dbctx lands squarely on a gap that this machine's own tooling exposes.** The `lwdb` skill queries the Linways V3/V4/local MySQL servers, but every session that touches a bug still spends its opening turns rediscovering which tables exist and how they join. dbctx compiles that into a portable file with zero LLM dependency — deterministic introspection, FK graph traversal, implicit-enum detection. It is PostgreSQL-only and Go, so the work here is a MySQL equivalent, which is a port rather than a research project. codegraph (07-30) indexes code, not schemas; nothing in the backlog does this.
- **airship is the most impressive thing on the list and the least buildable.** 215★ in a day for a Figma-like canvas that round-trips edits into Claude Code, Codex and OpenCode. `fills_gap = 1` — the visual-edit-to-agent-patch loop is genuinely missing for the Flutter and web work here — but a canvas editor is not one or two sessions, and MIT means installing it is the correct move if the loop proves useful.
- **mcptoon solves a problem this harness already solved.** 97% off tool discovery is a real number, and this session is carrying roughly 200 deferred MCP tools — but Claude Code ships deferred tools plus `ToolSearch`, which is the same mechanism. Worth installing for other clients; not worth building.
- **toolpermit is RunOnMine from two days ago with a different name.** Same local-first gating of agent tool calls, same week. Claude Code's permission modes and `PreToolUse` hooks already deny calls outright, and toolgate (07-23) covers the category in the backlog. Recorded so it stops resurfacing.
- **pi-gpt-search scores `novel = 1` and is still not something to build on.** It reaches an undocumented Codex search endpoint without an API key. That is a terms question before it is a technical one, and a dependency that dies the moment the vendor rotates auth cannot carry a daily-use tool — hence `fills_gap = 0` and `daily_utility = 0` despite the cleverness. If the need is real, the buildable version is an MCP wrapper over a search provider you hold keys for.
- **Venaya is the fifteenth personal-finance entry in this backlog.** expense-budget-tracker, finance-agent, frugon, monarch-mcp, local-finance-mcp, claude-finance-mcp, ledgerbot, finmcp, portfoliosage, finflutter, copilot-money-mcp, finance-assistant, financial-planning-agent and langalpha-invest all precede it. The no-bank-login manual ledger plus an LLM coach is a sound product and adds nothing the existing plans do not already specify. `fills_gap = 0` here means "the plan already exists", not "the interest is gone".
- **Hindcast and AI Pulse are both macOS-only against a Linux 5.15 machine**, and Hindcast additionally lands in the session-viewer category that the `csess` skill plus four backlog plans (sessionvault, claude-session-nexus, agentsession, deja-vu, sessionport) have already closed. Third independent session-indexer in four days.
- **Parley is priced infrastructure for a problem a solo developer does not have.** Agent-to-agent addressing with durable handoffs is a fresh primitive, and agent-link (also 2026-08-11, MIT, E2E encrypted) is the same idea shipped the same day — but the coordination gap only opens with a second human in the loop.
- **Also screened, not tabled:** Needle2 (491 pts, 14MB agentic LLM for phones and wearables — the most interesting model release in the window, but a model is not a weekend project), Implant (VS Code extension exposing editor APIs to agents — this workflow is terminal-based), Chopi and desktop-harness (both macOS-only agent sandboxing/control), opencode-hermes-memory (OpenCode-specific; memlayer, turnmem and atlaso-memory cover the category), and HERO-Anti-OverDefense (88★ paste-in contract against agent over-building — the `ponytail` skill already does this locally).
- **Flutter came up empty for the third day running.** GitHub's search API returns no Flutter-plus-AI repositories created since 2026-08-09, and the HN window has none. Finance produced only Venaya. Both remain live interests with nothing new shipping against them.
