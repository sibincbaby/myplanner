## Screening Notes

- **Finance lane remains closed.** Two candidates (TasniaNitu/finance-ai-assistant, simplynd/expense-ai) both scored ≥2 on interest and would have passed viability, but the standing instruction holds: no new finance plans until an existing one is built.

- **hz is the strongest find.** The pseudocode-as-prompt paradigm is genuinely new: instead of throwing away the prompt after generation, it persists `.hz` files alongside the generated code. Edits are just pseudocode changes — Huzzah diffs and regenerates only the impacted parts. This addresses the "loss of intent" problem in complex AI-assisted codebases and is the first tool this discovery run has found that rethinks the prompt lifecycle rather than the agent lifecycle. Early experiment, rough edges expected, but buildable in a single session.

- **anywhere-agents solves the "config drift" problem.** Every coding agent (Claude Code, Codex, Copilot, Cursor, Aider) has its own rules file in its own format. anywhere-agents maintains one `~/.agents/config.json` that a daemon syncs to all of them. The portable writing rules, permission guard (blocks destructive commands before they run), and custom skill references translate to each agent's native format. This is immediately buildable and daily-useful if you switch between agents.

- **Permit0 is the most production-ready find this cycle.** 214 stars, Apache 2.0, EU AI Act compliance angle (August 2026), Cedar policy language for formally-verified decisions. Doesn't need a build plan because the SDK is the artifact. Wire it to any active project.

- **Writing-rules cluster (kylehughes, yzhao062/agent-style, netresearch/git-workflow-skill, addyosmani/agent-skills).** Four distinct writing/skill tools surfaced this cycle. None scored high enough for a build plan — the gap they fill is covered by skills that already exist in the toolkit, and addyosmani/agent-skills is the most comprehensive of the group (24 lifecycle skills). Worth a direct install rather than a build.
