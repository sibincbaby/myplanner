## Screening Notes

- **Source tool: WebSearch, not GitHub Search API.** The local agent queries `github.com/search/repositories` with date filters and gets precise creation dates, star counts, license, language, and size in a single call. This run used web search, which returns narrative summaries from third-party sites. Creation dates are absent for most entries; star counts are estimates. The candidates table should be treated as "surfaced by web in the last 24-48h" rather than "verified created 2026-08-19". The novelty check is correspondingly weaker.

- **Four non-viable candidates share the same shape: lots of prior art, zero builds.** Claude Code Agent Monitor scores `novel = 0` because it has 920 stars — it is not newly created, it was recently updated and surfaced in search results. YNAB MCP scores `fills_gap = 0` and `novel = 0` because 7+ YNAB MCP implementations were found in a single search; the prior plan directory already contains `copilot-money-mcp`, `finmcp`, `langalpha-invest`, `financial-planning-agent`, `finance-assistant`, `localcode`, and eight more, and none have shipped. claude-voice (softcery) scores `novel = 0` because five other `claude-voice` repositories were found alongside it in the same query. agent-cli (basnijholt) scores `weekend_buildable = 0` because the full suite (Whisper server, TTS server, macOS menu bar app, worktree management, RAG proxy) is months of work; an MVP voice-input server is buildable in a session, but that is `vocalmcp` (08-01) and `voxctrl` (08-01) and `speakoflow` (08-08) and `agent-cli/voice-edit.md` and five more plans, none built. The voice lane has nine unbuilt plans; a tenth is the wrong direction.

- **AgentHUD scores viable but the lane warning applies.** `hud-mode` (08-06), `claude-fleet` (08-06), `fuelgauge` (08-13), `recap` (08-13), and `aiusage-tracker` (08-07) are five agent-monitoring plans, all unbuilt. AgentHUD earns its slot on `novel = 1` because the cross-session live view + LLM daily digest combination is not in any of those five — they all focus on cost tracking or single-session display, not on a fleet view with a language model summarizing the day. The plan says clearly: run `hud-mode` for a week first. If `hud-mode` already answers "what did my agents do across all sessions", AgentHUD is the sixth unbuilt plan in a lane that does not need more plans.

- **Ante earns 4/4 on an honest read, not a generous one.** The MVP is not Ante: it is a Python script that calls a local OpenAI-compatible endpoint in a tool loop. That is genuinely buildable in one session, because all it is is "POST a messages array, parse tool\_use, call a function, loop." Ante's value as a discovery is not "build this" but "understand the loop" — the offline-binary distribution is months of Rust engineering. The plan acknowledges both halves. If the goal is actually running offline, install Ante; the plan exists for understanding what it does and how to adapt it.

- **Murmell's file-lock idea is the viable kernel; the cloud canvas is not.** The product ships a full cloud canvas with VM-per-session, multi-user real-time collaboration, and git integration. None of that is a weekend. But the file-lock-before-write hook for concurrent Claude Code sessions is one FastAPI endpoint and two shell scripts. Phase 1 in the plan is that kernel. If two parallel Claude Code sessions on the same repo currently produce merge conflicts (they do), the lock server solves a real problem in 3 hours. Everything after Phase 2 is Murmell's infrastructure play, not a weekend project.

- **contextkit is the cleanest 4/4 of the four.** No prior plan covers the general "repo → structured agent context files" pipeline. `selfspec` (07-28) was about self-describing agent specs; `schemactx` (08-12) was DB schema extraction; `CLAUDE.md` files are written by hand. contextkit automates the part before the hand-writing: scan the repo, detect the framework, emit a template with the real facts filled in. Fully offline, deterministic, checks into git. The plan's Phase 1 alone (repo analysis) is useful as a standalone script even if the template system never gets built.
