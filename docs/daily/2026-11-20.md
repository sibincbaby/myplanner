## Scoring Notes

- **ADE Index** (3/4): the site itself isn't something to build. It is a source the pipeline doesn't use yet. Its sitemap lists 1,000 tool pages and 267 "alternatives" pages, and capability pages such as `directory?cap=worktree-isolation` return 97 tools in one request. Many of this log's `novel=0` kills land in exactly these categories: workbenches, orchestrators, remote control, worktrees. FG=1 because the broaden-the-query rule has flipped an apparent `novel=1` at least five times. DU=0 because the user never calls it directly; the cron does, and it only helps on the agent-tool share of candidates. Limits: its free-text search is weak (`session viewer` → 1 hit, while that lane is 8+ deep), and `atrium` comes back for every query, which looks like a sponsored slot.
- **dayfile** (2/4): this is an install, not a build (`pip install dayfile`, self-host). A feed-addressed append-only log with an MCP server isn't a clone of anything, so N=1. FG=0: the heartbeat feature ("source went quiet → open to-do") overlaps the 11-14 Agent Receipts cron-verifier plan and old dead-man's-switch tools, and the journal/log backlog already holds 12+ plans plus `lwr log`.
- **Wake** (2/4): its design is the best in the agent-journal lane. The model writes the note, then a script builds the Evidence section from real records and rejects drafts that cite missing refs. But the lane is an automatic `novel=0` (09-04: `devsql`, `whathaveidone`, `DevLog` and others), and `lwr log` already covers the work log. If anyone builds one of the backlog journal plans, copy the evidence-validator idea from here.
- **justless** (2/4): an install row, not a build. Prior art is large: `rtk-ai/rtk` (87k★) and `mksglu/context-mode` (34k★). justless pitches itself as "RTK + graphify + context pruning in one". FG=1 because neither is installed on this box. Before trying `justless wrap claude`, read what it relays: the README says it passes Claude Code's own traffic through.
- **Daksha** (2/4): a hosted web/phone app. Voice journaling with "ask your past" sits in the saturated voice-journal lane (about 10 plans, plus the `TinkeringDao/satori` install row from 11-11). Citing the source entry is the right UX; any backlog journal plan should copy it.
- **agentdiary** (1/4): same lane as Wake, but with no model and no evidence. Each entry is a manual `append`. Session-store adapters are still on its roadmap (P1).
- **find-tools** (1/4): FG=0 because `find-skills` is already installed in `~/.claude/skills`, and this pipeline's own prior-art rule does the same job. `kvadou/prior-art` (09-17) has the same pitch.
- **work3** (1/4): FG=0 because `claude --worktree` is first-party (the CHANGELOG has several 2.1.32x fixes for it). The lane is also 97 tools deep on ADE Index's `worktree-isolation` page.
- **Playgrounds** (0/4): a large app (planner, calendar, social-post pipeline with Remotion) built around someone else's workflow. The user plans in Redmine via `lwr`. The agent-task-board lane is saturated.
- **Hub by Icons8** (0/4): runs Claude Code with no permission prompts and sends decisions to a browser or Telegram. That is covered first-party by `claude agents` (the agents view with a waiting-on-you count) plus Remote Control, and the parallel-agents workbench lane is the largest one in this log.
