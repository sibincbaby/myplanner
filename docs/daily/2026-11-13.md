- **Handoffs** (2/4): Installable today with `claude plugin install handoffs@ghosthat-studio` (Linux supported). Same lane as aq (11-12), so install it instead of building one.
- **Reinwatch** (1/4): Per-agent token watchdog mod. `/context` plus the trace-pane lane (`claude-devtools`, `claude-tap`) already cover most of this, and runaway subagents are rare enough that you wouldn't use it daily.
- **SITREP** (1/4): Multi-machine server plus dashboard, so not a weekend build. Overlaps aq (11-12), Sheepdog and native Remote Control. Created 11-12, 6★.
- **Vibetime** (2/4): Repost: the repo dates from 2026-04-06 (53★) and installs with `npm i -g vibetime-cli`. Same lane as claw-diary (10-02) and agentjournal (07-25).
- **Halyard** (1/4): Native iOS plus SSH client is not a weekend build. Remote Control and the Rex mobile clients already cover the 'agents on my phone' gap.
- **Chengzhang (成章)** (2/4): Apple Silicon only, and dictation with LLM cleanup is crowded (Whisperstream, loudr, the voice-coder skill, speakoflow and symbol-aware-dictation plans).
- **30yr-uptime** (2/4): A cute idea, but the 'while Claude works' lane got 3 entries in 48h (this one, retro-break SNES, sporadic.app). A Stop/Notification hook plus a timer covers it.
- **Hisab** (1/4): Java Android with no AI layer, and it's an untested dev preview. The my-expance-flutter plan (11-09) and budget-widget (11-11) already cover this.
- **ELU** (0/4): A whole replacement harness, which isn't buildable in a weekend. Same lane as friday/duo/botference multi-vendor teams, which were marked novel=0 on 11-08.
