## Why each died

- **leanrea**: the most useful find today, but as something to install, not to build. The skill is one MIT `SKILL.md` that tells the agent which raw tool to use (asar, `go version -m`, otool/nm, jadx, apktool, Ghidra, binwalk) and lists the traps. Its benchmark on `claude -p` with Sonnet 5.5, 4 tasks × 3 reps: 388 s / $2.17 / 74 of 75 correct, against REA's 627 s / $3.36 / 75 of 75. Fills-gap is 1 on this machine: **the `rea` MCP server timed out on connect in this session**, and leanrea needs no server. Novel is 0 because it already exists and is 8 KB. Daily-utility is 0 because reverse engineering is occasional work. It is a direct alternative to the 10-13 plan [rea-mcp-reverse-engineer](/projects/2026-10-13-rea-mcp-reverse-engineer). Copy its `SKILL.md` (8,374 bytes) into `~/.claude/skills/leanrea/` and keep both until one proves itself. I read the file before recommending it. It already covers ELF on Linux (`readelf -hlSW`, `nm -D`, `objdump -d`). The only network call is `curl` against the website you are analysing, and nothing pipes a download into a shell.
- **Fundstash**: closed-source beta with no public repo. It is close to an already-shipped version of the 10-14 cloud plan [flutter-sms-expense-ai](/projects/2026-10-14-flutter-sms-expense-ai): Indian bank SMS auto-sync on Android, ML Kit receipt OCR, "chai 40" quick entry, Gemini Nano on device, and no account or cloud. That plan also missed open-source prior art: `qtw4c7phzx-alt/Moneyprism` (a Flutter app that parses bank, UPI and wallet SMS, created 04-20), `NodeNexus/SBETS` 37★, `allwin-antony/Expense_tracker`, plus 58 more on `upi sms expense`. The standing finance kill (`tomfunk/fungible`) applies too. **Before anyone builds the 10-14 plan, try Fundstash's Play beta and read Moneyprism's parser.**
- **switchboard**: the first-party **agents view** already does this. `claude agents` shows every session with a peek panel, and the footer shows "the count of agents waiting on you" (CHANGELOG 2.1.302). The agent-workbench lane is also the biggest on record (09-07 note).
- **orchestrator-skill**: first-party Claude Code covers it. Subagents run in the background by default, and 2.1.302 made that the rule in the desktop app and VS Code too, so the main session already never blocks. Fork subagents are on by default.
- **Reaper**: macOS 14+ only, and this machine runs Linux. The "reap processes agents leave behind" lane is 8 repos deep: `Agentinel` 50★, `tiagonrodrigues/agent-reaper`, `jwchang0206/rest-in-pid` (a Claude Code mod, 10-06), `clean-my-agent`, `claude-zombie-killer`, `portwatch` (TUI + MCP), `selviarora/baa`, and Reaper itself. Claude Code has also shrunk the problem: exit now force-kills background commands that are still running after 1.5 s, and background Bash auto-stops. Its useful trick is the `CLAUDECODE` environment marker for spotting reparented ghosts. On Linux, `grep -l CLAUDECODE /proc/*/environ` does the same thing in one line.
- **OpsTrellis**: runs on Linux and works offline, so Fills-gap is 1. It is still the 9th or later entry in the saturated dictation lane (`OpenWhispr` 5828★, `TypeWhisper`, `amical`, `awesome-voice-typing`; 08-30 note). **If voice is wanted, install a release. Don't write voice plan #9.**
- **agent-session-bridge**: standing `ctxrs/ctx` kill (1121★) for session portability, plus first-party `--resume`/`--fork-session`.
- **piaz-switch**: the account-switch lane is closed (6 or more repos, 09-03 note).
- **jarvis**: macOS Swift talk demo with no code beyond the README so far. It sits in the voice lane and the diary lane, and there are 12 unbuilt journal plans in `docs/projects/`.
- **TokenForge**: treat it as a **suspected malware lure. Do not download anything from it.** Its GitHub description is word for word the one on `mksglu/context-mode` (30,478★): "Sandboxes tool output (98% reduction), persists se…". Its README is different (md5 does not match), and the main call to action is a `releases/download/…/TokenForge.zip` badge. The repo is 41 KB and was created and finished within one hour. That matches the cloned-description, zip-payload pattern. If you want the real tool, it is context-mode.
