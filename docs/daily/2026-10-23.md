## Why each died

- **comment-diff**: Nice idea, and it runs on this box (mods need 2.1.287+, box is on 2.1.304). But reviewing agent diffs with line comments is a 15+ repo lane: `persiyanov/herdr-reviewr` (929★), `dbachelder/slop-review` (50★), `Darna-Digital/reviewer`, `diffler`, `gilles-g/localpr`, `prless`, `paul-enz/reviewr.nvim` (10-20), `diffloupe` (10-20). So N=0. In bypass mode you rarely review edits line by line, so DU=0. If you want it anyway: `/plugin marketplace add formstep/claude-mod-comment-diff`.
- **Quick Budget**: Hits three interest areas (finance, mobile-first, voice). But the finance backlog rule (19+ unbuilt plans plus the 10-21 `mula` fork plan) sets FG=0, and natural-language expense entry is a 28+ repo lane, so N=0. It's also unlicensed.
- **one-board-two-hosts**: The pattern is new: one MCP server feeds an MCP App iframe in claude.ai *and* a Claude Code mod pane, kept in sync. `"mcp app claude code mod"` found only this repo, so N=1. But it's a task board, and the planner already has 12+ unbuilt task/log plans, with a 4-deep agent task-board lane behind it (`mixpeek/amux` 543★, `claude-code-studio` 144★, `tasktrooper` 118★, `joxo` 89★). So FG=0. It's worth keeping as a **reference demo** for any future mod + claude.ai connector plan.
- **claude-desktop-importer**: It fixes real, documented gaps in Claude Desktop's built-in CLI-session import (skips `claude -p` sessions, untrusted folders, ignores `/rename` titles; cites `anthropics/claude-code#89857`), so N=1. But Claude Desktop has no Linux build, and this box is Linux, so FG=0 and DU=0.
- **Chamber**: Built in Flutter, which fits the profile. But "AI tends your local Markdown notes and finds links" is a mature lane (`reorproject/reor` 8,539★, `obsidian-smart-connections` 5,517★), so N=0. Under the journal/notes backlog rule, FG=0. Two narrow phrasings returned 0–2 hits; only the broadened check surfaced the real prior art.
- **voice-summary**: A 9-repo lane. `kyleoliveiro/claude-speak` (09-27) has the exact same shape: Kokoro, a spoken summary of every reply. Behind it are `heardlabs/heard` (210★), `readless`, `cc-vox`, `claude-spoken-briefs` and `claude-voice-loop`. N=0. It's also built as English-listening practice for Korean speakers, not as a dev tool.
- **Diário de Bordo**: A WIP (stage 1, pt-BR only, Chrome Web Speech). `memex-lab/memex` (798★) is the standing kill for voice-to-AI-journal, and the journal backlog rule sets FG=0. Leaving a mic recording all day is also a hard sell.
- **Calends**: `ellite/Wallos` (8,730★) and `bscott/subtrackr` (475★) already cover self-hosted subscription tracking, so the MCP server is the only thing new. The finance backlog rule sets FG=0.
- **Showboard**: `antvis/mcp-server-chart` (4,402★) and `op7418/Generative-UI-MCP` cover charts-from-an-agent. This harness also already has the Artifact tool and a `dataviz` skill, so FG=0. The narrow phrasing found only Showboard itself; the broadened one found the lane.

It's also a neighbour of yesterday's `landmines` plan, which targets the more useful thing (known *bugs* at your pinned version, not just CVEs). `cve.now` (a free CVE feed for agents) launched on HN the same day.
