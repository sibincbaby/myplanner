## Viable Projects

- **[Claude Code Local — Offline AI on Apple Silicon](../projects/2026-09-27-claude-code-local-offline-ai-on-apple-silicon.md)** — Runs Claude Code's full API surface against local MLX models, no tokens, no cloud. The project proves the bridge exists; the build is a minimal OpenAI-compatible MLX server that accepts exactly the routes Claude Code hits (completions + streaming). Ships as a single `uvicorn` entry point and a model-download helper.

- **[jev-pilot — Per-Prompt Effort, Model, and Skill Routing](../projects/2026-09-27-jev-pilot-per-prompt-effort-model-skill-routing.md)** — A Claude Code plugin that fires a lightweight Jev decision call before every turn and sets reasoning effort, subagent model, and skill suggestion for that prompt. The 13% cost reduction figure is independently measurable: run eight tasks with and without it and compare token spend. The decision ledger makes the tuning loop concrete.

- **[memmy-agent — One Memory Hub for Every Agent You Run](../projects/2026-09-27-memmy-agent-cross-agent-shared-memory-hub.md)** — Shared, local-first memory store that any agent (Claude Code, Codex, OpenClaw, Hermes) can read and write via an OpenAI-compatible API. The gap it fills is real: switch from Claude Code to Codex mid-task and each agent starts cold. Memmy closes that by giving every agent the same `/memory` endpoint.
