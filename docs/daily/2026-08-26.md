## Screening Notes

- **memorix is the strongest find this cycle.** 692 stars with last commit on Aug 25, memorix solves a real pain: agent memory doesn't survive context resets, IDE switches, or handoffs between Claude Code, Cursor, and Codex. The MCP interface means all three write to the same SQLite store. The plan below builds a much simpler personal version — single-repo, no autopilot, no embeddings — to avoid depending on a complex third-party tool for something this central to the coding workflow.

- **Agent Plugins 1.0.0 (Aug 6) is the most strategically important find.** Amazon, Anysphere, Microsoft, OpenAI, and Vercel jointly released a vendor-neutral standard for packaging skills + MCP configs into a portable `plugin.json`. Skills are currently scattered across this repo, CLAUDE.md files, and ad-hoc `mcp.json` configs. Wrapping them in a single plugin that installs with one command across every agent is one session's work and eliminates the "which agent has which tool" confusion entirely.

- **claude-voice is early but the architecture is right.** The sentence-chunking innovation — begin TTS while Claude is still streaming — is genuinely novel. Sub-second latency on a local machine is achievable. The plan below adds a hands-free coding workflow not covered by any prior plan in the toolkit.

- **agent-skill-loader and claude-code-frontend-skills scored 2/4.** The skill loader is a useful thin bridge but fills no gap the user doesn't already work around. The frontend skill pack is well-made but the review/refactor space is already saturated — Effeilo's four skills don't add coverage beyond what's available via existing skill packs.
