## Why each died

- **vupai**: Novel approach (Parakeet MLX for on-device ASR into tmux panes), and macOS-native with no cloud keys. Nonetheless FG = 0: the voice-input lane is at 9+ tools already (08-30 and 10-18 notes: `OpenWhispr` 5828★, `TypeWhisper`, `amical`, `awesome-voice-typing`, `voice-to-code`, `claude-code-voice`, `mcp-voice-hooks`, `mahmut`, `OpsTrellis`). The specific tmux injection angle is covered by `hns` (`claude "$(hns)"`, 10-16). Until this machine uses voice input daily, the lane stays closed.

- **GoogleCloudPlatform/scion**: Genuinely interesting — Go binary, Docker/Podman/Kubernetes runtimes, each agent gets its own git worktree and credentials, Apache 2.0, runs Claude Code + Gemini CLI + Codex + OpenCode in parallel. `weekend_buildable` = 0: this is container infrastructure, not a 1-session project; standing it up requires Docker and credential management across providers. `daily_utility` = 0 here because the primary workflow is single-agent. Worth revisiting if multi-repo parallel work becomes regular.

- **AIR Blackbox**: A complete pip package (`pip install air-blackbox-mcp[full]`) with 14 pattern-based regex checks mapped to EU AI Act articles. It is a ready-made tool to _install_, not an inspiration to _build_. FG = 0 for this workflow (EU AI Act compliance is not a daily task); DU = 0 for the same reason. If Python AI work picks up, `pip install air-blackbox-mcp` and run it as a pre-commit hook.

- **Dexicon**: The problem it solves — team context loss across AI coding sessions — is real and unsolved in this toolkit. But WB = 0: it appears to be a closed-beta SaaS with no public repo or SDK. Without an open codebase there is no MVP to build. Bookmarking dexicon.ai; if it ships an open-source agent or MCP component, reconsider.

- **hwatu**: Linux-only WebKitGTK browser with an MCP `open_url/screenshot/interact` interface. The "agent verification browser" angle is interesting but FG = 0: agent browser control is covered by `browser-use` (20k★+), `Playwright`-based MCP servers, and the first-party Claude Code built-in browser. Old (~82 days from today = late July) and Linux-only. Score 1/4.

- **Yobiru**: Agent-to-agent messaging over Tailscale. Interesting niche: if you run agents on multiple machines (desktop + cloud, two cloud VMs), this gives each agent a channel to the others. FG = 0 because this machine only ever runs one agent host; no Tailscale is currently installed. DU = 0 for the same reason. Revisit if the multi-machine workflow materialises.
