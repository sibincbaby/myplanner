## Viable Projects

- **[AgentUI — Rich Interactive UIs for Coding Agents](../projects/2026-09-28-agentui-rich-ui-interactions-for-coding-agents.md)** — An MCP server that gives coding agents (Claude Code, Cursor, Gemini CLI) the ability to show real UIs — sliders, forms, diffs, live previews — instead of asking free-form questions and guessing at values. The gap is real: every parameter-heavy agent operation currently asks a plain text question, the user types a number, the agent misrenders it. An MVP is a Node.js MCP server exposing `ui_ask` and `ui_create`, a sandboxed React frontend served locally, and auto-registration with the major agents. Achievable in one session.

- **[DiaryX — Private Flutter Diary with On-Device LLM](../projects/2026-09-28-diaryx-private-flutter-diary-with-on-device-llm.md)** — A Flutter diary app where an on-device Gemma 3n model (via Ollama first, then MediaPipe) expands voice or text entries, summarises the week, and tracks mood — all without any network call. The key differentiator is the "zero-telemetry" constraint: the LLM never phones home. Prior Flutter diary apps rely on cloud APIs or skip AI entirely. The source repo proves the MediaPipe Flutter integration compiles; the build starts from Ollama and graduates to MediaPipe in Phase 5.

- **[agent-messenger — Multi-Platform Messaging CLI for AI Agents](../projects/2026-09-28-agent-messenger-multi-platform-messaging-cli-for-ai-agents.md)** — A TypeScript/Bun CLI and SDK that lets an AI agent send messages across Slack, Discord, and Teams acting as the user (not as a bot), using extracted desktop-app session tokens. The novel angle: bot-based messaging requires OAuth setup per workspace; this uses the session the user already has. An MVP scoped to Slack + Discord fits in a weekend and is independently useful. The daily-utility ceiling is "runs inside CI/CD and autonomous agent pipelines" — less compelling as a day-one habit, which keeps it at 3/4.

The correct action is to use it as infrastructure, not rebuild it. `weekend_buildable=0`.
