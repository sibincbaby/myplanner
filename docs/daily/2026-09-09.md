- **The most valuable new fact of the day is regulatory, and it should become a standing rule.** `BankMCP` is the only 0/4 on the sheet, and it earns every zero. Enable Banking is a PSD2 aggregator: its 2,700+ banks are European. An India-based user's HDFC/ICICI/SBI/Axis accounts are not reachable through it at all, which is `daily_utility=0` on platform grounds before any other consideration. The Indian equivalent, RBI's Account Aggregator network (Setu, Finvu), restricts Financial Information User access to entities regulated by RBI, SEBI, IRDAI or PFRDA, with Sahamati/ReBIT certification required to go live — so **building this thesis on Indian rails is a licensing project, not a weekend project**, and `weekend_buildable=0` is a fact about the law rather than about the code. Searches confirmed the gap is real and unfilled: for India there are only reference-data servers (`rehan1020/MCP-India-Stack` — IFSC/PAN/GSTIN/UPI VPA lookups) and merchant-side rails (Pine Labs/NPCI autonomous UPI MCP). Nothing reads a retail user's own Indian bank transactions, and now we know why. **New rule: any open-banking candidate is `daily_utility=0` unless it names a rail that reaches Indian retail accounts. The reachable ingestion path is statement PDFs, SMS and UPI mails — a different thesis, and one `local-finance-mcp` already claims.**

- **`offload` is a textbook case of being one month and 517 stars late.** Its thesis — a `PreToolUse` hook stops a large `Read` and hands the file to a cheap worker so the bytes never enter the main context — is exactly `shunt`, shipped inside `spotify/portal-ai-plugins` (520★, Apache-2.0, created 2026-07-23): a `check-file-size` hook with a 350-line default threshold, a companion `check-bash-read` hook catching `cat`/`head`/`tail`, and a `bulk-reader` skill on Gemini 2.5 Flash, with a Spotify Engineering post measuring ~90% bulk-read token savings. **The candidate repo was created 2026-09-08 — the day after that post went wide.** Claude Code also covers the need first-party: the Explore subagent is read-only, runs on Haiku by default, and returns excerpts rather than file bodies. Worth logging for anyone tempted by the mechanism regardless: open issues #21460, #34692 and #40580 show `PreToolUse` hooks do not reliably fire on — or can circularly block — subagent tool calls, which is a structural weakness of this whole interception design.
