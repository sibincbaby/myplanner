## Screening Notes

- **us-vs-them is the find of the day, and the reason is a local one.** This repo's `CLAUDE.md` forbids the `Co-Authored-By: Claude` trailer, so the usual provenance signal does not exist in any commit here. Upstream sidesteps that by making you name the commits (`--ours` / `--theirs`) — which is exactly the part worth replacing, because Claude Code session transcripts already record every `Edit`/`Write` with a file path and a timestamp. That join is real evidence rather than a heuristic, and nothing in the backlog does it: brain0 (07-05) audits AI-generated code but needs instrumentation set up beforehand.
- **unyolo lands on a rule that is currently enforced by nothing but prompt discipline.** `CLAUDE.md` says to confirm personal (`sibincbaby`) versus work (`sibinc`) before creating a remote or pushing, and to keep `git@github-personal:` off work repos. Today an agent obeys that because it remembers to. A broker makes it a policy match. mcpaudit (08-09) *inspects* what the connected servers can reach; this *withholds* the credential. Complementary, not overlapping.
- **mirror** is well made and fails for the same reason wallfacer failed yesterday: the `csess` skill already lists and reads sessions for a folder, and the backlog holds four session-index plans (sessionvault, claude-session-nexus, agentsession, deja-vu). Two independent Show HNs in two days indexing Claude Code transcripts confirms the category is saturated, not that it is open.
- **faaah** is the cleverest 308 lines on the list — an OpenAI-compatible endpoint whose transport is the filesystem. It scores `novel = 1` and `fills_gap = 0`: the `gateway-endpoint` skill already provides a localhost OpenAI-compatible URL for dev-time work. Worth noting the upstream README limits it to local, non-commercial use; routing an agent subscription through an API shim is a terms question before it is a technical one.
- **patchloom** is not weekend-buildable — 1,826 commits and parsers for 20+ languages — and the gap is thin: the native `Edit` tool plus `jq`/`yq` handle structured edits today. Comment-preserving config edits are a genuine differentiator, hence `novel = 1`, but that is an argument for installing it, not rebuilding it.
- **RunOnMine** duplicates the harness. Claude Code already ships permission modes and `PreToolUse` hooks that can deny a call outright, and toolgate (07-23) covers runtime gating in the backlog. It is also 0★ and pre-1.0 for something whose whole value is being trustworthy.
- **swarm-forge** carries Uncle Bob's name and 2.0k stars, and still adds nothing here: the `Workflow` tool, the `Agent` tool and worktree isolation are already in this harness, with exPardus/fleet and claude-fleet in the backlog on top of that.
- **mcp-tester** arrived one day after the mcpaudit plan was written and overlaps it almost exactly, down to the A–F grading and rug-pull detection — but at 0★ against the official MCP Inspector and authgent. Recorded so it stops resurfacing; the mcpaudit plan stands.
- **Also screened, not tabled:** VoiceOS App Store (PH #2, 233 votes — voice-native micro-apps in the notch; novel packaging, but proprietary, macOS/Windows-only, and voice is the most saturated area in this backlog), Tura (542★ Rust agent runtime, 77.5% fewer tokens — an interesting `command_run` macro idea, but a runtime is not a weekend and ponytail/paleo/token-diet already cover token discipline), and DocsAlot CLI (PH #6, 129 votes — hosted docs SaaS; this repo is already VitePress plus an agent).
- **Personal finance and Flutter both came up empty again, for the second day running.** HN Algolia returns zero stories matching `expense tracker` or `flutter` in the window, and web search surfaced only repos already in `seen.json` (curiopay, expense-budget-tracker, PocketLLM, flutter-ai-labs) plus undated topic pages. The backlog's finance plans stay ahead of what is shipping.
