## Scoring Notes

- **Agent Receipts** (3/4): The closest match to a pain this repo already has. The nightly `claude -p` discovery job keeps reporting success after a step silently no-ops (write-digest with 0 tool calls, update-seen not writing, sidebar drift), and the checks are re-run by hand every day. Agent Receipts reads `~/.claude/projects/` and has `--project`, `--format json` and `--fail-on` (exit 4), so it can be scripted. It's installable today (`pipx install git+…`, created 11-12, 1★), so N=0. The plan is an integrate-and-extend: run it after the cron job and add the repo-specific on-disk checks. It is not a rewrite.
- **Diktat** (2/4): A clever idea. It calls the same speech-to-text endpoint that Claude Code's `/voice` uses, with keyterm prompting so `vLLM`/`nginx` come out right. But it's macOS-only, the endpoint is undocumented and uses the Claude Code OAuth token (a ToS and breakage risk), and inside Claude Code `/voice` already does this. Linux dictation is a saturated lane (open-whisper, utter-npu, plus the symbol-aware-dictation and voice-to-code plans).
- **Agentview Chat** (2/4): Windows-only. It's a repost (created 10-20). The native `claude agents`/`claude attach` views, Remote Control, aq (11-12) and cloudcli (07-01) already cover "see and reply to background sessions".
- **ReceiptExtractor** (2/4): The zero-app architecture is worth noting: MacroDroid forwards bank/wallet notifications to a Google Apps Script web app, which writes to a Sheet with Gemini categories and sends a daily Telegram report. But it's built for Israeli card issuers, and the SMS-expense lane already has 10+ plans (flutter-sms-expense-ai 10-14, pennywiseai 10-02, my-expance-flutter 11-09, budget-widget 11-11).
- **Money Tracker** (1/4): A self-build fork of PennyWise AI (already seen and planned 10-02). Needs JDK 21 + SDK 37. Nothing new for the user.
- **LocalLedger AI** (1/4): Its "the model never does arithmetic; every figure in the answer is checked against tool output" rule is a good pattern to borrow for the existing finance MCP plans. As a project it's macOS + US-CSV, in a lane with 15+ finance plans.
- **Harness** (1/4): A2UI messages rendered as native Flutter widgets is a new idea, but a full mobile agent runtime isn't a weekend build, and hermes-mobile-app (10-26) covers the phone-agent gap.
- **omut** (1/4): The agent-memory lane is saturated (lorekit 11-09, beacon 11-10, breadcrumbs 09-25, kage 10-12). It's a repost (created 11-01).
- **Lore** (1/4): Same lane as breadcrumbs (09-25, decision memory for coding agents). It's a repost (created 10-27).
- **analyse-bottleneck** (0/4): A large tool. `/context`, claude-tap and claude-devtools already cover most of it, and wall-clock attribution isn't something you'd check daily.

## Worth Trying Instead of Building

- **Agent Receipts**: try `agent-receipts --agent claude-code --project myplanner --since 1d` against last night's cron session before building anything (see the plan's Phase 0). Skip `agent-receipts install`: it writes command files under `~/.claude`, and this run doesn't need them.
- **LocalLedger AI**: read its "check every figure against tool output" verifier before working on any of the finance MCP plans.
