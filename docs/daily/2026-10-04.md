## Viable Projects

- **[Vault: UserPromptSubmit context-injection hook for Claude Code](../projects/2026-10-04-vault-context-injection-hook-for-claude-code.md)** — A Rust binary that hooks Claude Code's `UserPromptSubmit` event, searches an indexed store of project notes and past decisions via BM25 + cosine similarity, and injects the top-K chunks into each prompt within a token budget. Zero stars and nine commits, so it's early-stage, but the hook pattern is clean and the concept is immediately useful for keeping Claude's context loaded without manual pasting. A personal version built in 1-2 sessions (TypeScript hook + SQLite FTS5, skipping the Rust embedding layer) would run in every session.

- **[Dokoro: five-layer agent memory MCP](../projects/2026-10-04-dokoro-five-layer-agent-memory-mcp.md)** — Provides five memory layers — working, episodic, semantic, procedural, and *affective* (tracks which tools succeed or fail per agent) — over SQLite + LanceDB. The affective layer is genuinely novel: existing memory MCPs (Memsync, claude-mem) store what was done, not which tools were reliable. The result is smarter routing: if a tool keeps failing in a project, the agent routes around it next time. MVP (working + episodic + affective) is TypeScript + SQLite + MCP SDK in 1-2 sessions.

- **[MyFinance MCP: hosted personal-finance MCP server](../projects/2026-10-04-myfinance-mcp-hosted-personal-finance-server.md)** — Remote MCP server (TypeScript + Express + Prisma/PostgreSQL) with 28 tools for expense logging, budget tracking, and net-worth reporting, plus OAuth 2.1 for the claude.ai connector. One star, 115 commits — it works. Prior plans in this repo (Local Finance MCP, Claude Finance MCP) were local-only; this one is hosted, which unlocks the native claude.ai chat integration so the user can log expenses in a conversation without opening a terminal. MVP: 5 core tools + SQLite (dropping Postgres) in 1-2 sessions.

- **[Nezha: parallel AI coding-agent desktop app](../projects/2026-10-04-nezha-parallel-coding-agent-desktop.md)** — Electron desktop app that runs multiple Claude Code and Codex sessions in parallel across projects, with a unified task queue, session playback, and Git integration. 1.7k stars, last push June 2026. Not weekend-buildable in full, but inspired the plan: a lightweight Node.js TUI (Ink) that spawns and multiplexes N Claude Code processes in one terminal window with a task distributor. Herdr (July 2026) was similar but terminal-only and process-agnostic; this plan is narrower and Claude-Code-specific.
