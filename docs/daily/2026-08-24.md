- **apache/maka is the strongest find.** The append-only log (model messages, tool calls, permission decisions as an immutable sequence) is a genuinely different architecture from both claude-code's in-memory context and loopx's YAML state files. The recovery story is: if a session crashes, replay the log and rebuild state. Prior plan loopx (08-21) does goal tracking in YAML files; maka does full tool-call fidelity as an event stream. These are complementary, not duplicates.

- **AgentMux's tmux injection is the most novel engineering idea this cycle.** Instead of calling the Claude API directly, AgentMux drives existing CLI agent sessions via tmux `send-keys`, which means it runs on subscriptions you already pay for (Claude Max, Codex, GitHub Copilot) with zero additional per-token cost. The structured PM→Architect→Plan→Code→Review state machine, with file-based handoffs between phases, is a direct answer to the "how do I run a multi-role team without a $20/hour API bill" problem. This is buildable in Python + tmux in a single session.

- **video-vision is the only candidate outside the agent-management cluster.** It scored 3/4 rather than 4/4 only because `daily_utility = 0` (not every day). The specific use case — analyzing recorded tutorial videos, replaying a bug from a screen recording, understanding what happened in a CI video artifact — is not daily but is high-value when it comes up. No prior plan covers this.
