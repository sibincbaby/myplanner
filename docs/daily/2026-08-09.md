## Screening Notes

- **Wallfacer** is the best-built thing on the list today and still fails: the `csess` skill already lists and reads Claude Code sessions for a folder, and the backlog holds four session-index plans (sessionvault, claude-session-nexus, agentsession, deja-vu). Indexing sessions is a solved problem here. What is *not* solved is moving one — hence agent-hop over wallfacer.
- **captain-miao**: a fleet dashboard is now the third of its kind in the backlog (herdr 07-13, claude-fleet 08-06, agent-deck 08-07). Well executed, zero remaining gap.
- **remembrane**: contradiction detection plus a full time-travel audit trail is a genuine differentiator, so `novel = 1`. But memory is the single most-covered area in this backlog — atlaso-memory, memsync, turnmem, memlayer, cog-brain — and the local `memory/` directory already handles the daily case. Nothing left to fill.
- **Toolport**: solves tool-list bloat, which Claude Code now solves upstream — MCP tools are deferred behind `ToolSearch` and load their schemas on demand. Building a local gateway for this would duplicate the harness.
- **49Agents**: the interesting sliver is phone/tablet control of running sessions with no SSH, but that is covered four times over (cloudcli 07-01, pulse 07-15, pocketclaw 08-01, claude-code-app 08-05). The canvas itself is a desktop app plus a WebSocket relay — well past a weekend.
- **Utter**: voice capture is the most saturated interest area in the backlog (voxdiary-flutter, localmic, voxctrl, vocalmcp, echocode, voicecode, speakoflow). Voice-to-todo is also a decade-old category. No novelty left.
- **Cross-session messaging** is the notable platform news, not a project: it lands `ListAgents`/`SendMessage` natively, which retires the agent-messenger (07-06) plan and makes agmsg and Cowchat redundant. The one build-shaped hook it exposes — `CLAUDE_CODE_MESSAGING_SOCKET`, postable from any script — is also already covered upstream by `channels` for external events.
- **Personal finance turned up nothing today.** HN, GitHub and Product Hunt yielded only zero-star scaffolds and one Yahoo-Finance MCP wrapper. The backlog's finance plans (finmcp, ledgerbot, finance-assistant, financial-planning-agent, langalpha-invest) are ahead of what is shipping.
