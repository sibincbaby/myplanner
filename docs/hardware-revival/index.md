# Hardware Revival Intelligence

A daily cloud routine that looks for overlooked hardware: devices that can be unlocked, reflashed, debloated, taken off the cloud or repurposed. It pays special attention to work where AI coding agents speed things up, and to devices worth buying used in India.

- **[India acquisition watchlist](./watchlist)**: devices worth buying, with verified prices only.
- **[Research log](./research-log)**: one line per run.
- **Daily reports** are listed in the sidebar, newest first.

Each day goes deep on one primary sector:

| Day | Primary sector |
|-----|----------------|
| Mon | A: Consumer electronics |
| Tue | B: Smart home / IoT |
| Wed | C: Computing / networking |
| Thu | D: Robotics / automation |
| Fri | E: Industrial / commercial |
| Sat | F: Automotive |
| Sun | G: Other overlooked hardware |

Every day also includes a cross-sector sweep of the last 7 days and an AI-assisted hardware hacking search. The research database is `state/hardware-db.json` and the routine spec is `routines/hardware-revival.md`. To change what the routine does, edit the spec.
