### 1. Salesforce — Data Import Wizard, Data Loader & Bulk API 2.0 (mass insert/update/upsert layer) `closed`

**Why it's powerful:** Every Salesforce org (~150k of them) constantly loads, migrates and mass-updates records: trade-show lists, territory realignments, owner reassignments, backfills after a new field ships. Bulk API 2.0 can push millions of rows with upsert-on-external-ID semantics.

**Why people bounce off it:** CSV field mapping (.sdl files), external IDs vs record IDs, resolving lookups and parent relationships, date/picklist formats, validation-rule and trigger failures, and cryptic error CSVs. One bad upsert silently corrupts thousands of records, so admins either fear it or hand it to a consultant.

**AI operator:** Takes a messy spreadsheet plus an intent. It infers mappings from Describe metadata, resolves lookups with SOQL, pre-validates against validation rules and picklist values, runs a sample dry batch, then launches the bulk job and explains/fixes failed rows in plain English with a corrected retry file.

**Killer example:** User says "Import this trade-show CSV as Leads, match companies to existing Accounts by domain, route anything over 500 employees to the Enterprise queue, and don't overwrite existing phone numbers." → AI maps columns, resolves Account IDs by domain, normalizes formats, runs a 20-row test, launches a Bulk API 2.0 upsert keyed on an external ID with phone excluded for existing matches, and returns "1,184 loaded, 16 failed (11 invalid State picklist, 5 duplicate rule) — here's the fixed retry file."

**Integration path:** Salesforce Bulk API 2.0 (`/jobs/ingest`, `/jobs/query`), REST sObject Describe + Tooling API for field/picklist/validation-rule metadata, Composite API for previews; `sf data import/upsert bulk` CLI as alternate path.

**Demand 5/5 · Buildability 4/5**

### 2. SurveyMonkey (survey logic + Analyze crosstab/filter layer) `closed`

**Why it's powerful:** One of the most-installed survey tools anywhere, with branching, piping, quotas, A/B tests, benchmarks and built-in crosstab analysis.

**Why people bounce off it:** Advanced branching (conditions on answers, contact data, custom variables; show/hide/invalidate) is a maze, and Analyze's compare rules, crosstabs and saved views are rarely used. Most users export to Excel and do it badly.

**AI operator:** A "survey engineer + analyst" pair. It builds surveys with pages, questions and logic from a description, sets up collectors, then turns business questions into filters/crosstabs (or client-side analysis over bulk responses) and writes up the findings.

**Killer example:** User says "Make a 10-question NPS survey; detractors get a 'what went wrong' page, promoters skip to a referral ask; then show me NPS by plan tier." → AI creates pages, questions and skip logic, launches a weblink collector, and once responses land returns NPS by tier with a significance note and the top 3 detractor themes.

**Integration path:** SurveyMonkey REST API v3 (`/surveys`, `/pages`, `/questions`, `/collectors`, `/responses/bulk`, `/rollups`, webhooks). Writing advanced-branching rules via API is unconfirmed — fallback is simple skip logic via API plus guided UI steps for the rest.

**Demand 5/5 · Buildability 4/5**

### 3. PostHog (insights, HogQL, cohorts/actions, feature flags & experiments) `OSS`

**Why it's powerful:** Open-source all-in-one product platform (100k+ companies): analytics, session replay, flags, experiments, surveys and a data warehouse, self-hostable.

**Why people bounce off it:** Founders and PMs face many insight types (trends, funnels, retention, paths, stickiness), the actions-vs-events distinction, property filters, HogQL for anything advanced, and easy-to-botch flag/experiment targeting rules.

**AI operator:** Turns product questions into saved insights, HogQL queries, cohorts and flags; pins results to dashboards and explains what changed.

**Killer example:** User says "Why did trial-to-paid drop last week? And roll the new onboarding to 20% of EU free-plan users." → AI builds a funnel broken down by plan and country, runs HogQL to locate the drop-off step, creates a 20% EU-free flag and links an experiment with the right goal metric.

**Integration path:** PostHog REST API (`/api/projects/:id/insights`, `/query` with HogQL, `/cohorts`, `/actions`, `/feature_flags`, `/experiments`, `/dashboards`) with a personal API key; works against cloud or self-hosted.

**Demand 4/5 · Buildability 5/5**

### 4. CapCut Desktop — timeline & draft layer (draft_content.json) `closed`

**Why it's powerful:** Hundreds of millions of users; a full free multi-track editor with keyframes, templates, auto-captions, effects and speed ramps.

**Why people bounce off it:** Casual creators can't handle multi-track layering, keyframe curves, consistent caption styling across hundreds of clips, or chopping long recordings into shorts. Repurposing one video into several formats is hours of dragging.

**AI operator:** Reads and writes CapCut drafts directly — builds, restyles and splits timelines from plain English, and hands back a draft that stays fully editable in CapCut.

**Killer example:** User says "Turn my 40-min podcast into 6 vertical shorts with bold yellow captions and zoom-punches on key lines." → AI transcribes, picks the moments, writes 6 9:16 drafts with styled captions and scale keyframes, and they appear in CapCut's draft list ready to export.

**Integration path:** No official API — read/write `draft_content.json` / `draft_meta_info.json` in the local drafts folder via open-source pyJianYingDraft / pyCapCut / capcut-cli. Risk: format changes between versions and ToS exposure; keep a version-pinned schema adapter.

**Demand 5/5 · Buildability 4/5**

### 5. Gmail + Google One storage-quota reclaim layer (Outlook.com / OneDrive as second connector) `closed`

**Why it's powerful:** Gmail search operators (`larger:`, `has:attachment`, `older_than:`, `category:`) plus Drive quota data can pinpoint exactly what is filling the shared 15 GB.

**Why people bounce off it:** Hundreds of millions hit "storage full" and either pay or stop receiving email. Few know the operators, that trash still counts, or how to strip attachments without losing threads; bulk delete in the UI is error-prone.

**AI operator:** Breaks storage down by sender, attachment type and age; proposes safe cleanup plans (save big attachments first, purge newsletters, dedupe Drive, empty trash/spam) and executes them reversibly after a dry run.

**Killer example:** User says "Free up 5 GB without touching anything from my family or my bank." → AI finds 6.2 GB of old newsletters, promo attachments and duplicate Drive videos, excludes protected senders, archives large attachments to a local zip, trashes the rest and empties trash.

**Integration path:** Gmail API (`users.messages.list` with `q=larger:10M`, `sizeEstimate`, `batchModify`/`batchDelete`), Drive API v3 (`about.get` storageQuota, `files.list` with `quotaBytesUsed`, md5 dedupe); Microsoft Graph mail/drive for the Outlook.com connector. Google Photos out of scope (Library API restricted since 2025).

**Demand 5/5 · Buildability 4/5**

### 6. Microsoft 365 authoring-side accessibility (Word / PowerPoint / Excel Accessibility Checker), Google Docs/Slides as second connector `closed`

**Why it's powerful:** Office already has every field needed to produce accessible documents (alt text, reading order, header rows, real heading styles) — fixing at the source beats remediating PDFs later.

**Why people bounce off it:** The checker spits out 40 warnings; each fix lives in a different pane (Selection Pane, Reading Order, Table Design, Format Shape), and nobody knows what good alt text looks like. EU Accessibility Act (June 2025) and ADA Title II (2026) deadlines make it mandatory for public bodies and their vendors.

**AI operator:** Audits the file, writes alt text from vision analysis (marking decorative images), fixes slide reading order, promotes fake headings to real Heading styles, marks table header rows, fixes low-contrast colors — then shows a diff for one-click approval. Distinct from the existing Acrobat (post-hoc PDF) entry.

**Killer example:** User says "Make this 60-slide training deck pass the accessibility checker." → AI writes alt text for 84 images, reorders shapes on 23 slides, adds unique slide titles, fixes 11 contrast failures and returns a compliance report.

**Integration path:** Office.js add-in (PowerPoint `Shape.altTextDescription` in PowerPointApi 1.10, Word `InlinePicture.altTextDescription` + paragraph styles, Excel shapes); batch mode via python-pptx / python-docx / Open XML SDK over OneDrive/SharePoint through Microsoft Graph; Google Docs/Slides API `description` fields.

**Demand 4/5 · Buildability 4/5**

### 7. Shopify — Metafields & Metaobjects (custom data modeling layer) `closed`

**Why it's powerful:** Lets any merchant attach structured data (size charts, ingredients, FAQs, lookbooks) to products, variants, customers, orders and collections and render it in Online Store 2.0 themes with no app.

**Why people bounce off it:** Namespaces/keys, type choices (`list.metaobject_reference`, `rich_text_field`, `rating`), definitions vs values, validations, and wiring fields to theme "dynamic sources". Most merchants leave data trapped in product descriptions or pay for a metafields app.

**AI operator:** An AI data modeler that turns a catalog need into metafield/metaobject definitions, backfills values by parsing existing descriptions, and binds them to theme sections. Distinct from the existing Shopify (general) and Discount Function entries.

**Killer example:** User says "Every shoe needs a material, a care-instructions block and a brand-wide size chart." → AI creates a `size_chart` metaobject + product metafield definitions, extracts material from 1,200 descriptions into typed values, creates 4 size-chart entries, links each product, and hooks fields to the product template's dynamic sources.

**Integration path:** Shopify Admin GraphQL API (`metafieldDefinitionCreate`, `metaobjectDefinitionCreate`, `metaobjectUpsert`, `metafieldsSet`, `bulkOperationRunMutation`); theme binding via `themeFilesUpsert` on template JSON.

**Demand 4/5 · Buildability 4/5**

### 8. Jira Service Management — Assets (formerly Insight) CMDB & AQL layer `closed`

**Why it's powerful:** The CMDB built into every JSM Premium/Enterprise site: object schemas, typed references, scheduled imports, and links from tickets to laptops, people, contracts and services.

**Why people bounce off it:** Admins abandon schema design, reference attributes and cryptic import mappings; agents can't write AQL. The CMDB goes stale and nobody queries it.

**AI operator:** Designs schemas/object types, writes and runs AQL, bulk creates/updates/links objects, and builds Assets custom fields for request forms — all from plain English. Distinct from the existing whole-app Jira entry.

**Killer example:** User says "Show every laptop whose warranty ends this quarter, assigned to someone in Sales, and open a refresh request for each." → AI writes `objectType = Laptop AND "Warranty End" < endOfQuarter() AND "Owner".Department = Sales`, runs it, and bulk-creates linked JSM requests.

**Integration path:** Assets REST API (`api.atlassian.com/jsm/assets/workspace/{id}/v1/`: objectschema, objecttype, objecttypeattribute, object/aql, object create/update, importsource) + Jira Cloud REST v3 for requests.

**Demand 4/5 · Buildability 4/5**

### 9. Adobe Acrobat Pro — Redaction, Sanitize & Bates numbering (PyMuPDF / Stirling-PDF headless backend) `closed`

**Why it's powerful:** Pattern-based redaction, hidden-metadata sanitizing, Bates stamping and redaction codes underpin legal discovery, FOIA, GDPR subject-access requests and HR investigations.

**Why people bounce off it:** Users don't realize a drawn black box isn't redaction until applied; search-and-redact patterns, redaction codes, Sanitize and Bates prefix/suffix settings are scattered across tools. Mistakes leak sensitive data.

**AI operator:** User describes what must not be disclosed; AI finds it (names, IDs, account numbers, privileged-counsel emails), proposes marks with reasons for review, then applies, sanitizes, Bates-stamps and writes a redaction log. Distinct from the existing Acrobat (accessibility/forms/preflight) entry.

**Killer example:** User says "Redact all SSNs, patient names and anything mentioning the settlement amount in these 300 PDFs, then Bates-number them ACME-000001 onward." → AI marks 1,142 items for review, applies them, strips metadata/hidden layers, stamps Bates numbers and exports a privilege/redaction log CSV.

**Integration path:** Acrobat JavaScript (`Doc.addAnnot({type:"Redact"})`, `applyRedactions()`) for desktop; PyMuPDF (`add_redact_annot`/`apply_redactions`) or Stirling-PDF REST for headless batch; Adobe PDF Services API for pre-redaction OCR.

**Demand 4/5 · Buildability 4/5**

### 10. Bitwarden Business/Enterprise organization admin (1Password Business as second connector) `OSS`

**Why it's powerful:** The shared-credentials system of record for millions of SMB/mid-market teams: collections, groups, enterprise policies, SSO/SCIM and an event log.

**Why people bounce off it:** "Accidental IT admins" get lost in the collection × group × permission matrix (view / edit / hide passwords / manage), enterprise policies (single-org, account recovery, remove individual vault), and clean offboarding. Nobody can answer "who can see the AWS root password?"

**AI operator:** An access-governance operator: answers effective-access questions, applies least-privilege changes, and runs joiner/mover/leaver flows, verifying every change against the event log.

**Killer example:** User says "Priya leaves Friday. Pull her access, list every shared credential she viewed in 90 days so we can rotate them, and give her replacement the same access." → AI enumerates her groups/collections, queries view events, writes a rotation list, clones memberships to the new user and schedules the revoke.

**Integration path:** Bitwarden Public Organization API (`/public/members`, `/public/groups`, `/public/collections`, `/public/policies`, `/public/events`) + `bw` CLI; 1Password via `op` CLI (`op user`, `op group`, `op vault user grant/revoke`), Events API and SCIM bridge.

**Demand 4/5 · Buildability 4/5**

### 11. Expensify — policy rules, approval workflows & custom export templates `closed`

**Why it's powerful:** Expenses, card reconciliation and accounting sync for millions of SMB/mid-market users; the policy engine plus template-driven export can emit almost any GL/ERP import file.

**Why people bounce off it:** Category/tag/report-field rules are buried in policy settings, and custom accounting exports require Expensify's FreeMarker-based template language. Most admins give up and clean CSVs by hand every month.

**AI operator:** Compiles plain-English expense policies and target export layouts into policy updates and validated FreeMarker templates, testing against real reports before saving.

**Killer example:** User says "Meals over $75 need a receipt and manager approval, travel codes to 6200 split by department tag, and export like our Sage Intacct import file." → AI updates categories, tags, rules and approvers, writes the export template, runs it on last month's reports and diffs the output against the sample file.

**Integration path:** Expensify Integration Server API (`requestJobDescription` jobs: `update` policy categories/tags/report fields/employees, `create` reports/expenses, `file`/`download` with custom FreeMarker templates).

**Demand 4/5 · Buildability 4/5**

### 12. Gusto — multi-state payroll setup, time-off policies & off-cycle payrolls `closed`

**Why it's powerful:** Payroll, tax filing and benefits for 300k+ US small businesses, including multi-state withholding, garnishments and contractor payments.

**Why people bounce off it:** A remote hire in a new state triggers state tax registration requirements, local taxes, PTO accrual rules and off-cycle bonus payrolls with supplemental withholding. Owners don't know which number goes where and end up paying an accountant.

**AI operator:** Interviews the owner in plain language, then fills state tax requirements, configures time-off policies and builds off-cycle/correction payrolls via API — previewing every change and net-pay impact before submission.

**Killer example:** User says "I hired a remote engineer in Colorado starting the 1st, and give everyone a $1,000 holiday bonus taxed as supplemental." → AI adds the employee and work location, lists the missing Colorado tax fields and fills what it can, creates the off-cycle bonus payroll with supplemental withholding, and shows the net-pay preview.

**Integration path:** Gusto API / Embedded Payroll API (REST, OAuth2: companies, employees, locations, state tax requirements, time-off policies, garnishments, payrolls incl. off-cycle, contractor payments). Partner app approval required — the main buildability risk.

**Demand 5/5 · Buildability 3/5**
